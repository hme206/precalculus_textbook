1.1 Relations & Functions

In mathematics we use a variety of different equations, formulas, and graphical representations to help explain phenomena that happens in the real world. Sometimes those phenomena involves more than one type of quantity, and we are trying to decide if there is some type of relationship between the two quantities, this is known as a relation. An example would be the relationship between the amount of interest accumulated in a bank account over a specific amount of time.

The equation \(I=prt\) which is the simple interest formula, can look like \(I=\$1000t\), this equation would be an example of a function.

Function

A relation f, from set A to a set B is a function if the x-value(input) does not repeat. In more technical terms if for every input there is only one output(y-value).

Determining Functions Algebraically

Example 4 on the previous page is a great lead into what we will discuss next. How do we determine if an equation is a function algebraically?

To determine this we take the algebraic equation and we solve it for the "y" variable. When it comes to functions we typically call the y-variable the dependent variable, because its value depends on the value that you plugged in or the x-value which we call the independent variable.

Example

Determine whether the following equations represent y as a function of x?

a.) \(x^2+3x-y=1\)

b.) \(x^2+y^2-2x=5\)

Solution

a.) If we were to solve for y in this equation we would get:

\[\begin{aligned} x^2+3x-y &= 1 \\ y &= x^2+3x-1 \end{aligned}\]

Notice, that regardless of what value you plug in for x only one value will come out for y, which makes this a Function.

b.) If we were to solve for y in this equation we would get:

\[\begin{aligned} x^2+y^2-2x &= 5 \\ y &= \pm\sqrt{5-x^2+2x} \end{aligned}\]

Notice how this one differs from the previous one in the manner that for every x-value we plug in we get two y-values back out. This is because anytime you take the square root of a number you don't know if that number was negative or positive to begin with.

Function Notation

Once we have determined that an equation is a function, using any of the methods we just covered, we can then take and write that equation in Function Notation. In this notation you take and swap the y for \(f(x)\).

The notation of \(f(x)\) does not mean f times \(x\), it is not an operation. What it does mean is the \(f\) is a function with variable \(x\), where x is the input variable.

Input Output Equation
\(x\) \(f(x)\) \(f(x)=x+3\)

We can use this notation to help us evaluate the function at given x-values or inputs. Lets suppose that we wanted to find \(f(0)\), \(f(-1)\), and \(f(3)\). To find these values all you have to do is plug each value into the equation where you see \(x\).

\(f(0)\) \(f(\color{red}{0}\color{black})=(\color{red}{0}\color{black})+3=3\)

\(f(-1)\) \(f(\color{red}{-1}\color{black})=(\color{red}{-1}\color{black})+3=2\)

\(f(3)\) \(f(\color{red}{3}\color{black})=(\color{red}{3}\color{black})+3=6\)

Keep in mind that while \(f(x)\) is the most commonly used notation, it is not the only notation that is possible. \(f\) is simply the name of the function. A function can be named anything. Just like the variable \(x\). The assigned variable can be a number of different letters of the alphabet. For example someone could use the notation \(h(t)=-1.6t^2+2t+560\) as a representation of the height of a rocket, \(t\) seconds after it is launched.

Example

Let \(h(x)=-x^2+4x-5\) evaluate the function for each of the values below.

a.) \(h(-2)\) b.) \(h(2s)\) c.) \(h(r+2)\)

Solution

a.) Replace \(x\) with \(-2\) and simplify the equation.

\[\begin{aligned} h(-2) &= -(-2)^2+4(-2)-5 \\ &= -(4)+(-8)-5 \\ &= -4-8-5 \\ &= -17 \end{aligned}\]

b.) Replace \(x\) with \(2s\) and simplify the equation.

\[\begin{aligned} h(2s) &= -(2s)^2+4(2s)-5 \\ &= -(4s^2)+8s-5 \\ &= -4s^2+8s-5 \end{aligned}\]

c.) Replace \(x\) with \(r+2\) and simplify the equation.

\[\begin{aligned} h(r+2) &= -(r+2)^2+4(r+2)-5 \\ &= -(r+2)(r+2)+4r+8-5 \\ &= -(r^2+4r+4)+4r+3 \\ &= -r^2-4r-4+4r+3 \\ &= -r^2-1 \end{aligned}\]

Note: Remember that \((r+2)^2\) is not as simple as squaring the \(r\) and the \(2\) you have to multiply the polynomial by itself and use either "foil" or the "box method" to multiply out the polynomials.

Domain & Range

When talking about functions and relations it is important to discuss their domains and ranges. The domain of a function is the set of all the inputs or x-values, if a value repeats we do not write that value you twice. Whereas the range is the set of all the outputs or y-values. Like with domain if a value repeats we don't list that value twice.

When it comes to writing a domain and a range, there are a number of different ways to do it. Lets take a look at some examples.

Example

Identify the domain and range of the relations given below. Then identify if the relation is a function.

a.) \(\{(3,4),(4,3),(5,3),(6,2),(4,4)\}\)

b.) \(\{(Blue,4),(Green,5),(Yellow,4)\}\)

c.) The table below represents the weights of females in their 30's.

Age Weight
34 135
35 145
30 125
34 145
37 155

Solution

a.) Domain: \(\{3,4,5,6\}\) Range: \(\{2,3,4\}\)

This is a relation because the x-value of 4 is in two different relationships.

b.) Domain: \(\{Blue, Green, Yellow\}\) Range: \(\{4,5\}\)

This is a function, if you notice none of the input values go to more than one output value.

c.) Domain: \(\{30,34,35,37\}\) Range: \(\{125,135,145,155\}\)

This is a relation because the Age of 34 appears twice and goes to two different y-values or weights.

When it comes to the domain and range of a equation algebraically, things get a bit more complicated. We will discuss this situation and how to answer those questions later on in the chapter.
