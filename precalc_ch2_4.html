CH 2.4 – Graphing Polynomials

In a previous section we worked on graphing quadratic functions, which is a polynomial function. When it comes to graph sketching for polynomials the quadratic and linear functions are definitely the easiest of them all. The further you dive into polynomial functions and their graphs the more complex it starts to get. In this course we are going to lay the basic foundations for graphing polynomials, to prepare you to further dive into the process in Calculus.

When it comes to graphing polynomials there are a number of characteristics that a polynomial possesses that will assist us in trying to graph them. The first that we are going to look at is the Leading Coefficient Test.

The Leading Coefficient Test — Part A: When n is Odd

Allow \(f(x)\) to be a polynomial function of degree \(n\), where \(x\) moves without bounds from left to right. When \(n\) is odd, there are two possible end behaviors depending on the sign of the leading coefficient \(a_n\).

The Leading Coefficient Test — Part B: When n is Even

When \(n\) is even, both ends of the graph move in the same direction, determined by the sign of \(a_n\).

End Behavior: Leading Coefficient Test

Example

Explain the end behavior of the following functions using the leading coefficient test.

  1. \(f(x) = 3x^3 + 3x - 3\)
  2. \(g(x) = -4x^4 - 2x^2 + 4x\)
  3. \(h(x) = 3 - x^5\)

Solution

  1. \(f(x)\) is a polynomial of degree \(3\) which means that \(n\) is odd. Next we identify \(a_n = 3\), that means that \(a_n > 0\). Since this polynomial is odd and \(a_n > 0\) that means that the left-hand side of the polynomial goes down (\(x \to -\infty,\ f(x) \to -\infty\)), and the right-hand side of the polynomial goes up (\(x \to \infty,\ f(x) \to \infty\)).

  2. \(g(x)\) is a polynomial of degree \(4\) which means that \(n\) is even. Looking at the leading coefficient \(a_n = -4\) which means that \(a_n < 0\). Therefore we can determine that both ends of this polynomial go the same direction which is down (\(x \to \pm\infty,\ f(x) \to -\infty\)).

  3. \(h(x)\) is a polynomial of degree \(5\), which means that \(n\) is odd. We can see that \(a_n = -1\) which means that \(a_n < 0\) suggesting that the right end of the graph will go down and the left side of the graph will go up (\(x \to -\infty,\ f(x) \to \infty\) and \(x \to \infty,\ f(x) \to -\infty\)).

Now, I am sure you've figured out that this really doesn't help us determine what happens between the end points of our graph — this just gives us an idea of what the ends do. Another characteristic that helps us to graph a function are the real zeros of the function.

Real Zeros and Turning Points

Example

Using the polynomial \(f(x) = -4x^5 + 8x^3\), identify all real zeros of the function, and the maximum number of turning points the graph will have.

Solution

In order to find the zeros of \(f(x)\) we first have to set \(f(x) = 0\) and solve. To do that we will have to factor \(f(x)\).

\[ \begin{aligned} 0 &= -4x^5 + 8x^3 \\ &= -4x^3(x^2 - 2) \end{aligned} \]

By setting each factor equal to zero we would find the zeros of this function.

\[ \begin{aligned} -4x^3 &= 0 \\ x^3 &= 0 \\ \sqrt[3]{x^3} &= \sqrt[3]{0} \\ x &= 0 \end{aligned} \]
\[ \begin{aligned} x^2 - 2 &= 0 \\ x^2 &= 2 \\ \sqrt{x^2} &= \sqrt{2} \\ x &= \pm\sqrt{2} \end{aligned} \]

The number of turning points that \(f(x)\) has is \(n - 1 = 5 - 1 = 4\).

Based on what we previously said a graph of a function has at most \(n\) real zeros. But we only found three zeros. This happens because in this function some of our zeros are repeated. Keep in mind that if you had an imaginary zero, they have to come in pairs, which count as two zeros not just one.

Repeated Zeros

Repeated Zeros

If \((x - a)^k\) is a factor of \(f(x)\) where \(k > 1\), then \(x = a\) is a repeated zero with a multiplicity of \(k\).

  1. If \(k\) is odd, then the graph crosses the \(x\)-axis at \(x = a\).
  2. If \(k\) is even, then the graph touches the \(x\)-axis at \(x = a\), but does not go through it.

That means based on our example the graph would cross through the \(x\)-axis at \(x = 0\) because \(k = 3\); it also goes through the \(x\)-axis at \(x = \pm\sqrt{2}\) because in those cases \(k = 1\).

Example

Find and describe the real zeros of the function. Also determine the maximum number of turning points possible for \(g(x) = 2x^3 - 6x^2\).

Solution

The maximum number of turning points would be \(n - 1 = 3 - 1 = 2\). To find the zeros and their multiplicity we first need to factor the polynomial and solve for \(x\).

\[0 = 2x^2(x - 3)\]
\[ \begin{aligned} 2x^2 &= 0 \\ x &= 0 \end{aligned} \]
\[ \begin{aligned} x - 3 &= 0 \\ x &= 3 \end{aligned} \]

This graph would cross through the \(x\)-axis at \(x = 3\), and the graph would touch the \(x\)-axis but not go through it at \(x = 0\) since it has a multiplicity of two.

Looking at the graph we can see that at \(x = 0\) the graph does in fact touch the \(x\)-axis but does not go through it, then at \(x = 3\) it crosses through the \(x\)-axis as we had found using our multiplicity. Also notice that we said that \(g(x)\) would have two turning points. We can see that in the graph as well at \(x = 0\) and at \(x = 2\).

Now we are going to put together all of the pieces that we've learned in this section up to this point, in order to graph a polynomial. As we stated earlier we are laying the ground rules for graphing polynomials. In Calculus you will dive much further into this idea.

Basic Guidelines for Graphing Polynomials

Basic Guidelines for Graphing Polynomials

  1. Write the polynomial in standard form and apply the Leading Coefficient Test to identify the end behavior.
  2. Find the zeros of \(f(x)\).
  3. Find the \(y\)-intercept if one exists.
  4. Find additional points between the zeros and \(y\)-intercept to help determine the shape of the graph.
  5. Sketch the graph using the pieces outlined in the previous four steps.

Example

Sketch the graph of \(f(x) = -4x^3 + x^4 - 3x^2 + 18x\).

Solution

Step 1: Standard Form and End Behavior

Remember that we first need to write our polynomial in standard form, which means that our exponents need to go in decreasing order:

\[f(x) = x^4 - 4x^3 - 3x^2 + 18x\]

Next we need to identify our leading coefficient \(a_n\) and our degree to identify the end behavior.

\(a_n = 1\) — positive
\(n = 4\) — even

Since our leading coefficient is positive and our degree is even that means the end behavior of our graph will have both ends going upward, or more specifically: as \(x \to -\infty,\ f(x) \to \infty\) and as \(x \to \infty,\ f(x) \to \infty\).

Step 2: Find the Zeros

Next we need to identify our zeros of \(f(x)\). To do that we may need to apply all of the processes and rules that we learned in the previous section. First we will need to factor out an \(x\) from all the terms.

\[f(x) = x(x^3 - 4x^2 - 3x + 18)\]

This means there is a zero at \(x = 0\). Next we can apply Descartes' Rule to the polynomial inside the parentheses to identify the type of zeros that we may have.

Positives

\[f(x) = \textcolor{blue}{+}x^3 \textcolor{red}{-} 4x^2 \textcolor{red}{-} 3x \textcolor{blue}{+} 18\]

We can see that there are two sign changes so that means we will have either two or zero positive zeros.

Negatives

\[ \begin{aligned} f(-x) &= (-x)^3 - 4(-x)^2 - 3(-x) + 18 \\ &= \textcolor{red}{-}x^3 \textcolor{red}{-} 4x^2 \textcolor{blue}{+} 3x + 18 \end{aligned} \]

There is one sign change in \(f(-x)\); this means that there is only one negative zero for the polynomial.

We can see that \(x = 3\) is a zero of \(f(x)\). Now we can solve the quadratic that the result leaves us with to find the remaining zeros. We will call it \(g(x)\).
\[ \begin{aligned} g(x) &= x^2 - x - 6 \\ &= (x - 3)(x + 2) \end{aligned} \]
\[(x - 3) = 0 \implies x = 3\]
\[(x + 2) = 0 \implies x = -2\]

This means that \(f(x)\) has zeros at \(x = -2,\ 0,\ 3\). We can also see there is a multiplicity of two for the zero \(x = 3\), which means that at that point the function will touch the \(x\)-axis but not go through it.

Step 3: Identify the \(y\)-Intercept

Remember the \(y\)-intercept occurs when \(x = 0\), thus:

\[f(0) = 0^4 - 4(0)^3 - 3(0)^2 + 18(0) = 0\]

giving us a \(y\)-intercept of \((0,\ 0)\).

Step 4: Build a Table of Values

Now that we know our \(x\)-intercepts and \(y\)-intercept we can create a table to evaluate the function at several other values to help us with the shape of this graph. The values below that appear in red are values that you select on your own. The values you pick aren't really all that important; the important part is that they are values between what we are going to call critical values — these would be your zeros (\(x\)-intercepts) and \(y\)-intercepts.
