CH 2.5 – Rational Functions

Another type of function that contains polynomials are Rational Functions. These types of functions are the quotient(s) of two polynomial functions, and are written in the form of

\[f(x) = \frac{N(x)}{D(x)}\]

where \(D(x)\) is any nonzero polynomial of any degree. Rational functions have domains that are restricted by values that make the denominator any number except zero. This is where we have to be careful, because it is possible for some denominators to equal zero. When that happens we end up with a fraction that is undefined, meaning that it doesn't exist at that given point. We call these points discontinuities. They can be further defined as removable discontinuities (holes) or non-removable discontinuities (vertical asymptotes), depending on whether the rational function can be reduced to eliminate a common factor in the denominator and numerator.

Vertical Asymptotes

Vertical Asymptote

Assuming that \(f(x)\) is a rational function in simplest terms, the line \(x = a\) is a vertical asymptote of the graph of \(f(x)\) when \(f(x) \to \infty\) or \(f(x) \to -\infty\).

The vertical asymptote(s) \(x = a\) can be found anywhere \(D(x) = 0\).

In a rational function, a vertical asymptote is a line that the function will get infinitely close to but never actually touch. To find vertical asymptote(s) you first have to make sure that your rational function is in simplified form. This means that if you factor the numerator and denominator there are no common factors. If there are common factors this creates something known as a hole.

Example

Find the vertical asymptote and any holes for the rational functions.

  1. \(\displaystyle f(x) = \frac{x^2 + x - 6}{x^2 - 6x + 8}\)
  2. \(\displaystyle g(x) = \frac{x^2 + 3x}{x^2 + 2x - 8}\)
  3. \(\displaystyle h(x) = \frac{x + 3}{x^2 + 2}\)

Solution

1. First we need to factor our numerator and denominator to see if we have any common factors.

\[f(x) = \frac{(x-2)(x+3)}{(x-2)(x-4)}\]

Notice how we have an \((x - 2)\) in the numerator and denominator. This means that this rational function has a hole in the graph at \(x = 2\). This would leave us with the rational function of

\[f(x) = \frac{(x+3)}{(x-4)}\]

To find the vertical asymptote you take the portion of the denominator that is left and set it equal to zero, then solve for \(x\).

\[x - 4 = 0\] \[x = 4\]

That means that \(f(x)\) has a vertical asymptote at \(x = 4\).

2. Once again we start by factoring both the numerator and denominator of the rational function to get

\[g(x) = \frac{x(x+3)}{(x+4)(x-2)}\]

This rational function has no common factors, meaning that there are no holes in this graph. That means that we need to set each factor in the denominator equal to zero, then solve for \(x\).

\[\begin{aligned} x + 4 &= 0 \\ x &= -4 \end{aligned}\]
\[\begin{aligned} x - 2 &= 0 \\ x &= 2 \end{aligned}\]

This means that we have a vertical asymptote at \(x = -4\) and \(x = 2\). It is possible for a rational function to have more than one vertical asymptote.

3. Looking at \(h(x)\) it can be seen that there is no way to factor the numerator or the denominator. The polynomial on the top doesn't match the polynomial on the bottom so that means this function has no holes. To locate our vertical asymptote we'd set the denominator equal to zero and solve for \(x\):

\[\begin{aligned} 0 &= x^2 + 2 \\ -2 &= x^2 \\ \sqrt{-2} &= x \\ i\sqrt{2} &= x \end{aligned}\]

We have a problem here. We know that \(\sqrt{-2} = i\sqrt{2}\), which is an imaginary number. That means that this function does not have any vertical asymptotes.

It is important to keep in mind that a rational function does not have to have a vertical asymptote. When this happens it will typically have another type of asymptote that will aid you in graphing the function. The other types of asymptotes that a rational function can have are horizontal asymptotes or oblique (slant) asymptotes.

Horizontal Asymptotes

Horizontal asymptotes are also important aspects of a rational function. While a little bit more involved to find, they still provide valuable information for graphing. While the graph of a rational function cannot pass through or touch a vertical asymptote, it is possible for the graph of a rational function to pass through or touch a horizontal asymptote.

Horizontal Asymptote

The horizontal asymptote \(y = b\) can be found when:

  1. If the degree of the numerator is equal to the degree of the denominator, then \[y = \frac{\text{Leading Coefficient of the Numerator}}{\text{Leading Coefficient of the Denominator}}\]
  2. If the degree of the numerator is less than the degree of the denominator, then \(y = 0\).
  3. If the degree of the numerator is greater than the degree of the denominator, then there is no horizontal asymptote.

Example

Identify the horizontal asymptote (if it exists) for each example below.

  1. \(\displaystyle f(x) = \frac{2x - 5}{-4x + 3}\)
  2. \(\displaystyle g(x) = \frac{x - 1}{x^2 + 2x + 1}\)
  3. \(\displaystyle h(x) = \frac{x^3 + 2x^2 + x}{x - 4}\)

Solution

1. Any time we look at a rational function we should always try to factor first to see if it needs to be reduced. Fortunately for us \(f(x)\) cannot be factored, meaning it's already in its simplest form. That means we go straight to looking at the degree of the numerator and denominator.

Degree of the numerator \(= 1\)
Degree of the denominator \(= 1\)

Since the degree of the numerator is equal to the degree of the denominator, our horizontal asymptote is at

\[y = \frac{\text{Leading Coefficient of the Numerator}}{\text{Leading Coefficient of the Denominator}}\] \[\begin{aligned} f(x) &= \frac{\textcolor{blue}{2}x - 5}{\textcolor{red}{-4}x + 3} \\[6pt] \Rightarrow\quad y &= \frac{\textcolor{blue}{2}}{\textcolor{red}{-4}} = -\frac{1}{2} \end{aligned}\]

2. Once again we want to first factor our rational function to see if there are any common factors. There are no common factors. Moving right on to finding the degree of the denominator and the degree of the numerator.

Degree of the numerator \(= 1\)
Degree of the denominator \(= 2\)

In this problem the degree of the numerator is less than the degree of the denominator, which tells us that our horizontal asymptote is at \(y = 0\).

3. For this problem, it doesn't reduce or contain any holes. We will just move on to the degree of the denominator and the degree of the numerator.

Degree of the numerator \(= 3\)
Degree of the denominator \(= 1\)

With the degree of the numerator being greater than the degree of the denominator, this rational function does not have a horizontal asymptote. Instead it may have an oblique asymptote.

Oblique Asymptote

If our rational function doesn't have a horizontal asymptote then it could possibly have an oblique asymptote. But this will only happen if the degree of the numerator is exactly one more than the degree of the denominator once the rational function has been reduced. Finding an oblique asymptote requires us to use division.

Example

Find the oblique asymptote for \(\displaystyle f(x) = \frac{x^2 + 2x + 1}{x - 4}\).

Solution

Use long division (or synthetic division where applicable) to find the equation of the oblique asymptote.

\[\require{enclose} \begin{array}{r} x + 6 \phantom{{}+ 25} \\[-3pt] x - 4 \enclose{longdiv}{x^2 + 2x + 1} \\[-3pt] \underline{-(x^2 - 4x)} \phantom{{}+ 1} \\[-3pt] 6x + 1 \\[-3pt] \underline{-(6x - 24)} \\[-3pt] 25 \end{array}\]

The line \(y = x + 6\) is the equation of the oblique asymptote.

Guidelines for Graphing Rational Functions

Now that we've learned how to find the asymptotes of a rational function, let's define an outline on how to graph rational functions.

Guidelines for Graphing Rational Functions

  1. Identify all asymptotes of the rational function.
  2. Identify the zeros of the rational function.
  3. Find the \(y\)-intercept \(f(0)\).
  4. Find values between the asymptotes and zeros to help define the general shape.
  5. Plot the graph, first placing the asymptotes and critical points on the graph, and then connecting the dots using smooth lines — being sure not to cross any vertical asymptotes.

Example

Sketch the graph for \(\displaystyle f(x) = \frac{2x+3}{3x^2+7x-6}\).

Solution

Step 1: Factor and Find Asymptotes

Start by factoring the numerator and denominator to determine if there are any common factors, then find the asymptotes.

\[f(x) = \frac{2x+3}{3x^2+7x-6} = \frac{2x+3}{(x+3)(3x-2)}\]

Note how there are no common factors; this means we can move on to finding our asymptotes.

a.) Vertical Asymptote(s):

Set the denominator equal to zero:

\[(x+3)(3x-2) = 0\] \[(x+3) = 0 \quad \text{and} \quad (3x-2) = 0\] \[x = -3 \quad \text{and} \quad x = \tfrac{2}{3}\]

b.) Horizontal Asymptote:

Degree of the numerator \(= 1\)
Degree of the denominator \(= 2\)

Since the degree of the numerator is less than the degree of the denominator, our asymptote is at \(y = 0\).

c.) Oblique Asymptote:

There is no oblique asymptote because there is a horizontal asymptote.

Step 2: Find the Zeros

To find the zeros of a rational function you set the numerator equal to zero and solve for \(x\).

\[\begin{aligned} 2x + 3 &= 0 \\ 2x &= -3 \\ x &= -\tfrac{3}{2} \end{aligned}\]

Step 3: Find the \(y\)-Intercept

The \(y\)-intercept is found by substituting zero into the function.

\[\begin{aligned} f(0) &= \frac{2(0)+3}{3(0)^2+7(0)-6} \\[6pt] &= \frac{3}{-6} \\[6pt] &= -\tfrac{1}{2} \end{aligned}\]

Step 4: Build a Table of Values

Insert critical values (vertical asymptotes and zeros) to help identify values between them, and evaluate the function at each of those values.

\(x\) \(-4\) \(-3\) \(-2\) \(-\tfrac{3}{2}\) \(0\) \(\tfrac{2}{3}\) \(1\)
\(f(x)\) \(-\tfrac{5}{14}\) ASY \(\tfrac{1}{8}\) \(0\) \(-\tfrac{1}{2}\) ASY \(\tfrac{5}{4}\)

Step 5: Sketch the Graph

Place the asymptotes on the graph using dotted lines, plot the points, and connect with a smooth curve.

By looking at this graph we can see that the function does cross our horizontal asymptote, which is allowable — it just can't cross the vertical asymptotes.

Example

Sketch the graph of \(\displaystyle g(x) = \frac{x^2 - x}{x + 1}\).

Solution

Step 1: Factor and Find Asymptotes

Start by factoring the numerator and denominator to determine if there are any common factors, then find the asymptotes.

\[g(x) = \frac{x^2 - x}{x+1} = \frac{x(x-1)}{(x+1)}\]

Note how there are no common factors; this means we can move on to finding our asymptotes.

Vertical Asymptote(s):

Set the denominator equal to zero:

\[(x+1) = 0\] \[x = -1\]

Horizontal Asymptote:

Degree of the numerator \(= 2\)
Degree of the denominator \(= 1\)

Since the degree of the numerator is greater than the degree of the denominator, there is no horizontal asymptote.

Oblique Asymptote:

Since there is no horizontal asymptote, there may be an oblique asymptote. We find this using long division:

\[\begin{array}{r} x - 2 \phantom{{}+ 2} \\[-3pt] x + 1 \enclose{longdiv}{x^2 - x} \\[-3pt] \underline{-(x^2 + x)} \\[-3pt] -2x \phantom{{}+ 0} \\[-3pt] \underline{-(-2x - 2)} \\[-3pt] 2 \end{array}\]

Our oblique asymptote is the equation \(y = x - 2\).

Step 2: Find the Zeros

\[\begin{aligned} x(x-1) &= 0 \\ x = 0 \quad &\text{or} \quad x - 1 = 0 \\ x = 0 \quad &, \quad x = 1 \end{aligned}\]

Step 3: Find the \(y\)-Intercept

\[\begin{aligned} g(0) &= \frac{(0)^2 - 0}{0 + 1} \\[6pt] &= \frac{0}{1} \\[6pt] &= 0 \end{aligned}\]

Step 4: Build a Table of Values

Insert critical values (vertical asymptotes and zeros) and evaluate the function between them.

\(x\) \(-2\) \(-1\) \(-\tfrac{1}{2}\) \(0\) \(\tfrac{1}{2}\) \(1\) \(2\)
\(g(x)\) \(-6\) ASY \(\tfrac{3}{2}\) \(0\) \(-\tfrac{1}{6}\) \(0\) \(\tfrac{1}{3}\)

Step 5: Sketch the Graph

When graphing rational functions, as you can see, the asymptotes provide you with a lot of direction and information. The zeros and the points are used to aid you in finding a general shape; otherwise you may not know where the graph will go.
