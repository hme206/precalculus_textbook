CH 2.6 – Polynomial and Rational Inequalities

Throughout this section we've been building on how to solve polynomial functions, which is an essential skill to be able to graph and solve rational functions. In the previous section we discussed the graphs of rational functions. We found in these graphs that they have asymptotes, zeros, and a number of other characteristics. All of these pieces play an important role in solving inequalities.

Polynomial Inequalities

When it comes to solving any type of inequality we have to use the functions to find zeros of the functions. When pertaining to inequalities we call these values critical values. These values help us to set up a "test interval" that we would need to determine where the function is positive or negative.

Outline for Solving Polynomial Inequalities

  1. Step 1. Swap the inequality sign for an equality sign.
  2. Step 2. Set the equation equal to zero.
  3. Step 3. Solve the polynomial function.
  4. Step 4. Set up the test intervals using the zeros found in the previous step, and test each interval to determine if it is negative or positive.
  5. Step 5. Based on the signs found in Step 4, conclude the intervals that make the expression valid using the original inequality symbol.

Example

Solve \(f(x) = x^3 + 3x^2 \geq x + 3\).

Solution

Step 1: Swap the Inequality for an Equality

\[x^3 + 3x^2 \geq x + 3\] \[x^3 + 3x^2 = x + 3\]

Step 2: Set the Equation Equal to Zero

\[\begin{aligned} x^3 + 3x^2 &= x + 3 \\ x^3 + 3x^2 - x - 3 &= 0 \end{aligned}\]

Step 3: Solve the Polynomial

In some cases we may need to use all the steps used throughout this chapter. However, this expression can be solved by factoring by grouping.

\[\begin{aligned} x^3 + 3x^2 - x - 3 &= 0 \\ x^2(x + 3) - 1(x + 3) &= 0 \\ (x + 3)(x^2 - 1) &= 0 \end{aligned}\]
\[x + 3 = 0 \qquad x^2 - 1 = 0\] \[x = -3 \qquad\quad x = \pm 1\]

Step 4: Set Up Test Intervals

This means that we can set up a number line and find test values between each zero to determine the interval sign. The values you choose to evaluate the function at are yours to choose — they just have to be values between the critical values. You plug those values into the function to evaluate the sign.

Test Interval Test Value Polynomial Value Positive / Negative
\((-\infty, -3)\) \(x = -4\) \((\textcolor{red}{-4})^3 + 3(\textcolor{red}{-4})^2 - (\textcolor{red}{-4}) - 3 = -12\) Negative
\((-3, -1)\) \(x = -2\) \((\textcolor{red}{-2})^3 + 3(\textcolor{red}{-2})^2 - (\textcolor{red}{-2}) - 3 = 3\) Positive
\((-1, 1)\) \(x = 0\) \((\textcolor{red}{0})^3 + 3(\textcolor{red}{0})^2 - (\textcolor{red}{0}) - 3 = -3\) Negative
\((1, \infty)\) \(x = 3\) \((\textcolor{red}{3})^3 + 3(\textcolor{red}{3})^2 - (\textcolor{red}{3}) - 3 = 48\) Positive

Step 5: Conclude

Now we have to conclude and identify our answers. With inequalities it is important to remember that there isn't one singular value answer — it is always a range of values that make the statement true. Looking back at our original statement \(x^3 + 3x^2 \geq x + 3\), we had a greater than or equal to sign. This tells us that we need the positive intervals, and since it includes the equal to, we use square brackets (except for \(\pm\infty\)). The positive intervals are \((-3, -1)\) and \((1, \infty)\), so our solution is:

\[[-3,\,-1] \cup [1,\,\infty)\]

Example

Solve \(2x^3 - 3x^2 - 32x < -48\).

Solution

Step 1: Swap the Inequality for an Equality

\[2x^3 - 3x^2 - 32x < -48\] \[2x^3 - 3x^2 - 32x = -48\]

Step 2: Set the Equation Equal to Zero

\[\begin{aligned} 2x^3 - 3x^2 - 32x &= -48 \\ 2x^3 - 3x^2 - 32x + 48 &= 0 \end{aligned}\]

Step 3: Solve the Polynomial

\[\begin{aligned} 2x^3 - 3x^2 - 32x + 48 &= 0 \\ x^2(2x - 3) - 16(2x - 3) &= 0 \\ (2x - 3)(x^2 - 16) &= 0 \end{aligned}\]
\[2x - 3 = 0 \qquad x^2 - 16 = 0\] \[x = \tfrac{3}{2} \qquad\quad x = \pm 4\]

Step 4: Set Up Test Intervals

Test Interval Test Value Polynomial Value Positive / Negative
\((-\infty, -4)\) \(x = -5\) \(2(\textcolor{red}{-5})^3 - 3(\textcolor{red}{-5})^2 - 32(\textcolor{red}{-5}) + 48 = -117\) Negative
\(\left(-4,\, \tfrac{3}{2}\right)\) \(x = 0\) \(2(\textcolor{red}{0})^3 - 3(\textcolor{red}{0})^2 - 32(\textcolor{red}{0}) + 48 = 48\) Positive
\(\left(\tfrac{3}{2},\, 4\right)\) \(x = 3\) \(2(\textcolor{red}{3})^3 - 3(\textcolor{red}{3})^2 - 32(\textcolor{red}{3}) + 48 = -21\) Negative
\((4, \infty)\) \(x = 5\) \(2(\textcolor{red}{5})^3 - 3(\textcolor{red}{5})^2 - 32(\textcolor{red}{5}) + 48 = 63\) Positive

Step 5: Conclude

Looking back at our original inequality \(2x^3 - 3x^2 - 32x < -48\), our symbol is less than but not equal to, which tells us we need round brackets. Since it is less than, we are looking for the negative intervals, which are \((-\infty, -4)\) and \(\left(\tfrac{3}{2}, 4\right)\). Our solution is:

\[(-\infty,\,-4) \cup \left(\tfrac{3}{2},\,4\right)\]

Graphically on our number line:

It is important to take note of the difference between the inequalities with equal to symbols and those without — it can be the difference between a correct answer and an incorrect answer. Also, while in both examples our intervals of positive and negative alternated, this is not always the case. You cannot just assume that if one interval is positive the next will be negative. It is possible for them all to be positive or all to be negative. If you're not sure when this happens, check the multiplicity of the critical value. If the critical value has an odd multiplicity, the sign will change. If the critical value has an even multiplicity, the sign will stay the same.

Rational Inequalities

The process for solving rational inequalities is very similar to that for solving polynomials. There are just a few things that we have to take into account. For example, rational functions can have vertical asymptotes, and if an interval contains one of those asymptotes as a critical value, then regardless of what the sign is for our inequality we never include the asymptote — meaning we always use round brackets at asymptote values.

Outline for Solving Rational Inequalities

  1. Step 1. Swap the inequality sign for an equality sign.
  2. Step 2. Set the equation equal to zero.
  3. Step 3. Find the critical points.
    • a.) Vertical asymptotes.
    • b.) Zeros of the rational function.
  4. Step 4. Set up the test intervals using the zeros found in the previous step, and test each interval to determine if it is negative or positive.
  5. Step 5. Based on the signs found in Step 4, conclude the intervals that make the expression valid using the original inequality symbol.

Example

Solve \(\displaystyle\frac{x-7}{x+2} \geq \frac{x-9}{x+3}\).

Solution

Step 1: Swap the Inequality for an Equality

\[\frac{x-7}{x+2} \geq \frac{x-9}{x+3}\] \[\frac{x-7}{x+2} = \frac{x-9}{x+3}\]

Step 2: Set Equal to Zero

We are actually going to skip this step. Since we have a single rational function on each side, we can cross-multiply, which is a much easier approach.

Step 3: Find the Critical Points

Since we have rational functions on each side, we can cross-multiply. This cannot be done with all rational equations, so be careful. Cross-multiplying gives:

\[\begin{aligned} (x-7)(x+3) &= (x+2)(x-9) \\ x^2 - 4x - 21 &= x^2 - 7x - 18 \end{aligned}\]

Bringing everything to one side:

\[\begin{aligned} x^2 - 4x - 21 - x^2 + 7x + 18 &= 0 \\ 3x - 3 &= 0 \\ 3x &= 3 \\ x &= 1 \end{aligned}\]

The reason this works is that when solving rational equations you only set the numerator equal to zero. Cross-multiplying creates a common denominator that allows us to essentially "add" our functions together. So our zero occurs at \(x = 1\). Now we need the vertical asymptotes to find the remaining critical points. To find vertical asymptotes, set each denominator equal to zero:

\[\begin{aligned} x + 2 &= 0 \\ x &= -2 \end{aligned}\]
\[\begin{aligned} x + 3 &= 0 \\ x &= -3 \end{aligned}\]

The critical points of this graph are \(\{-3,\,-2,\,1\}\).

Step 4: Set Up Test Intervals

Remember that the function you evaluate is not just \(3x - 3 = 0\). You have to include the denominators, so the function used to evaluate test values is \(\dfrac{3x - 3}{(x+2)(x+3)}\).

Test Interval Test Value Value of \(\dfrac{3x-3}{(x+2)(x+3)}\) Positive / Negative
\((-\infty, -3)\) \(x = -4\) \(\dfrac{3(\textcolor{red}{-4})-3}{(\textcolor{red}{-4}+2)(\textcolor{red}{-4}+3)} = -7.5\) Negative
\((-3, -2)\) \(x = -\tfrac{5}{2}\) \(\dfrac{3(\textcolor{red}{-\frac{5}{2}})-3}{(\textcolor{red}{-\frac{5}{2}}+2)(\textcolor{red}{-\frac{5}{2}}+3)} = 42\) Positive
\((-2, 1)\) \(x = 0\) \(\dfrac{3(\textcolor{red}{0})-3}{(\textcolor{red}{0}+2)(\textcolor{red}{0}+3)} = -1.5\) Negative
\((1, \infty)\) \(x = 2\) \(\dfrac{3(\textcolor{red}{2})-3}{(\textcolor{red}{2}+2)(\textcolor{red}{2}+3)} = \tfrac{3}{20}\) Positive

Step 5: Conclude

Going back to our original statement, our symbol was greater than or equal to. That typically means square brackets and positive values. However, we must remember that our positive interval \((-3, -2)\) contains asymptotes at both endpoints — we never use square brackets at asymptotes. The interval \((1, \infty)\) contains the zero \(x = 1\), which does get a square bracket. Our solution is:

\[(-3,\,-2) \cup [1,\,\infty)\]

Example

Solve \(\displaystyle\frac{3x}{x-1} \leq \frac{x}{x+4} + 3\).

Solution

Step 1: Swap the Inequality for an Equality

\[\frac{3x}{x-1} \leq \frac{x}{x+4} + 3\] \[\frac{3x}{x-1} = \frac{x}{x+4} + 3\]

Step 2: Bring Everything to One Side

In this rational function we can't cross-multiply because of the plus three. That means we have to bring everything to one side and then find the common denominator to solve.

\[\begin{aligned} \frac{3x}{x-1} - \frac{x}{x+4} - 3 &= 0 \end{aligned}\]

Step 3: Find the Critical Points

It does not matter whether you find the vertical asymptotes or the zeros first. This time we will find the vertical asymptotes first.

\[\begin{aligned} x - 1 &= 0 \\ x &= 1 \end{aligned}\]
\[\begin{aligned} x + 4 &= 0 \\ x &= -4 \end{aligned}\]

Next we find our zeros. To do that we must find the least common multiple and create rational expressions all with a common denominator.

\[\begin{aligned} \frac{3x}{(x-1)} - \frac{x}{x+4} - 3 &= 0 \\[8pt] \frac{3x(\textcolor{red}{x+4})}{(x-1)(\textcolor{red}{x+4})} - \frac{x(\textcolor{red}{x-1})}{(x+4)(\textcolor{red}{x-1})} - \frac{3\textcolor{red}{(x+4)(x-1)}}{\textcolor{red}{(x+4)(x-1)}} &= 0 \\[8pt] \frac{3x^2+12x}{(x-1)(x+4)} - \frac{x^2-x}{(x-1)(x+4)} - \frac{3x^2+9x-12}{(x-1)(x+4)} &= 0 \\[8pt] \frac{-x^2 + 4x + 12}{(x-1)(x+4)} &= 0 \end{aligned}\]

Don't worry about multiplying out the denominator — just leave it as the product of two binomials. Once you've combined your rational expressions, solve by setting the numerator equal to zero.

\[\begin{aligned} -x^2 + 4x + 12 &= 0 \\ -1(x^2 - 4x - 12) &= 0 \\ -1(x-6)(x+2) &= 0 \end{aligned}\]
\[x - 6 = 0 \qquad x + 2 = 0\] \[x = 6 \qquad\quad x = -2\]

Our critical values are \(\{-4,\,-2,\,1,\,6\}\).

Step 4: Set Up Test Intervals

Test Interval Test Value Value of \(\dfrac{-x^2+4x+12}{(x-1)(x+4)}\) Positive / Negative
\((-\infty, -4)\) \(x = -5\) \(\dfrac{-(\textcolor{red}{-5})^2+4(\textcolor{red}{-5})+12}{((\textcolor{red}{-5})-1)((\textcolor{red}{-5})+4)} = -5.5\) Negative
\((-4, -2)\) \(x = -3\) \(\dfrac{-(\textcolor{red}{-3})^2+4(\textcolor{red}{-3})+12}{((\textcolor{red}{-3})-1)((\textcolor{red}{-3})+4)} = 2.25\) Positive
\((-2, 1)\) \(x = 0\) \(\dfrac{-(\textcolor{red}{0})^2+4(\textcolor{red}{0})+12}{((\textcolor{red}{0})-1)((\textcolor{red}{0})+4)} = -3\) Negative
\((1, 6)\) \(x = 2\) \(\dfrac{-(\textcolor{red}{2})^2+4(\textcolor{red}{2})+12}{((\textcolor{red}{2})-1)((\textcolor{red}{2})+4)} \approx 2.667\) Positive
\((6, \infty)\) \(x = 7\) \(\dfrac{-(\textcolor{red}{7})^2+4(\textcolor{red}{7})+12}{((\textcolor{red}{7})-1)((\textcolor{red}{7})+4)} \approx -0.1364\) Negative

Step 5: Conclude

Our original statement had a less than or equal to sign, so we are looking for the negative intervals. Remember: asymptote values always get round brackets, regardless of the inequality symbol. The zeros \(x = -2\) and \(x = 6\) get square brackets; the asymptotes \(x = -4\) and \(x = 1\) get round brackets. Our solution is:

\[(-\infty,\,-4) \cup [-2,\,1) \cup [6,\,\infty)\]

Real-World Application: Profit Inequalities

There are a number of ways that inequalities can be applied to real-world situations. This includes topics such as cost, revenue, and profits for marketing research. In this type of model it is important to know that the profit a company makes is equal to the revenue they have coming in minus the cost they put out to produce the good.

Example

A marketing department for a slogan t-shirt company determines that the demand for their new t-shirt is

\[p = 100 - 0.00001x, \qquad 0 \leq x \leq 10{,}000{,}000\]

where \(p\) is the price per t-shirt (in dollars) and \(x\) represents the number of t-shirts sold. The revenue for selling \(x\) t-shirts is

\[R = x(100 - 0.00001x)\]

The total cost of producing \(x\) t-shirts is \(\$10\) per t-shirt plus a one-time set-up cost of \(\$2{,}500{,}000\), giving a total cost of

\[C = 10x + 2{,}500{,}000\]

What prices can the company charge per t-shirt to obtain a profit of at least \(\$190{,}000{,}000\)?

Solution

First we need to set up our equation.

Profit = Revenue − Cost

\[P = \bigl(x(100 - 0.00001x)\bigr) - (10x + 2{,}500{,}000)\] \[190{,}000{,}000 \geq \bigl(x(100 - 0.00001x)\bigr) - (10x + 2{,}500{,}000)\]

As with all our other inequalities, we need to simplify and bring everything to one side to solve for \(x\).

\[\begin{aligned} 190{,}000{,}000 &\geq x(100 - 0.00001x) - 10x - 2{,}500{,}000 \\ 190{,}000{,}000 &\geq 100x - 0.00001x^2 - 10x - 2{,}500{,}000 \\ 190{,}000{,}000 &\geq 90x - 0.00001x^2 - 2{,}500{,}000 \\ 0 &\geq 90x - 0.00001x^2 - 192{,}500{,}000 \end{aligned}\]

Applying the quadratic formula to find the zeros:

\[\begin{aligned} x &= \frac{-90 \pm \sqrt{(90)^2 - 4(-0.00001)(-192{,}500{,}000)}}{2(-0.00001)} \\[6pt] &= \frac{-90 \pm \sqrt{8100 - 7700}}{-0.00002} \\[6pt] &= \frac{-90 \pm \sqrt{400}}{-0.00002} \\[6pt] &= \frac{-90 \pm 20}{-0.00002} \end{aligned}\]

The zeros are at \(x = 5{,}500{,}000\) and \(x = 3{,}500{,}000\). We now find test values between those critical values:

\[\begin{aligned} P(3{,}000{,}000) &= -0.00001(3{,}000{,}000)^2 + 90(3{,}000{,}000) - 192{,}500{,}000 \\ &= -\$12{,}500{,}000 \\[6pt] P(4{,}000{,}000) &= -0.00001(4{,}000{,}000)^2 + 90(4{,}000{,}000) - 192{,}500{,}000 \\ &= \$7{,}500{,}000 \\[6pt] P(6{,}000{,}000) &= -0.00001(6{,}000{,}000)^2 + 90(6{,}000{,}000) - 192{,}500{,}000 \\ &= -\$12{,}500{,}000 \end{aligned}\]

From this we can see that the company needs to make between \(3{,}500{,}000\) and \(5{,}500{,}000\) t-shirts in order to achieve a profit greater than \(\$190{,}000{,}000\).

To find the corresponding price range, substitute the boundary values of \(x\) back into the demand equation \(p = 100 - 0.00001x\):

\[\begin{aligned} p(3{,}500{,}000) &= 100 - 0.00001(3{,}500{,}000) = \$65 \\ p(5{,}500{,}000) &= 100 - 0.00001(5{,}500{,}000) = \$45 \end{aligned}\]

The company should charge between \(\$45\) and \(\$65\) per t-shirt to obtain a profit of at least \(\$190{,}000{,}000\).

This is only one example of how inequalities can be applied in the real world. There are many others. The important part is that you still work through the same set of processes to solve the problem as you would with a regular polynomial.
