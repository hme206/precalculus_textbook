CH 3.1 – Exponential Functions and Their Graphs

In this text we've already discussed several of our parent functions including the linear, quadratic, polynomial, and the rational functions. While all of those functions can and do have roles in the real world, the next two functions that we will discuss in this chapter are most likely the two that have the most real-world application.

I am sure that at some point in your lives you've heard about carbon dating, decay and growth rates. These are just a few of the applications that Exponential Functions can be applied to.

Exponential Function

An Exponential Function of base \(b\) and exponent \(x\) can be denoted as

\(f(x) = b^x\)

where \(b\) is a fixed real number such that \(b > 0\), \(b \neq 1\), and \(x\) is any real number. Thus we call it an exponential function base \(b\).

Example

Evaluate the exponential functions at each given value.

Function Value
1. \(f(x) = 3^x\) \(x = -2\)
2. \(f(x) = 4^{-x}\) \(x = 1.6\)
3. \(f(x) = 0.6^x\) \(x = 5\)

Solution

Function Value Input Solution
1. \(f(x) = 3^x\) \(x = -2\) \(3^{-2} = \dfrac{1}{3^2}\) \(\dfrac{1}{9}\)
2. \(f(x) = 4^{-x}\) \(x = 1.6\) \(4^{-1.6} = \dfrac{1}{4^{1.6}}\) \(0.1088\)
3. \(f(x) = 0.6^x\) \(x = 5\) \(0.6^5\) \(0.07776\)

When we evaluate exponential functions, sometimes we need to use a calculator — as in the last two examples above — and other times we can evaluate them without one. It is important to remember that negative exponents can be made positive by moving the base number to the denominator and making the exponent positive, if the base is originally in the numerator (or vice versa if the base was originally in the denominator).

A special type of exponential function that we will use is something known as The Natural Base "e". The natural base "e" is very similar to that of the number \(\pi\). In mathematics we tend to use symbols for irrational numbers like these two — it is much easier to write the symbol than all of the decimal places, and since neither number can be calculated to all decimal places, using the symbol is the most accurate representation of the number. The number \(\textcolor{blue}{e = 2.718281828\ldots}\) and can be evaluated in your calculator by pressing the \(e^x\) button and substituting \(1\) for \(x\). When we use this number as a base in an exponential function we call it the natural exponential function.

Graphs of Exponential Functions

When it comes to graphing an exponential function, just like any other type of function, there are some specific properties that we need to be aware of to make graphing them a simpler process.

Just like any other parent function, the exponential function can be transformed using any of the transformations discussed in Chapter 1. The transformation that will play the largest role in the exponential function is the vertical translation, as exponential functions have horizontal asymptotes. If you move the graph up or down, the asymptote moves with the graph.

Example

Graph the exponential functions below, being sure to include the horizontal asymptote in the graph.

  1. \(f(x) = 0.25^x\)
  2. \(g(x) = -3^{x+1}\)
  3. \(h(x) = 4^x - 2\)
  4. \(k(x) = 2^{-x}\)

Solution

When it comes to graphing exponential functions we graph them like we would any other function — by creating an \(x\), \(y\) table and plotting our points.

1. \(f(x) = 0.25^x\)

When creating the table remember that you select the \(x\)-values that you'll plug in to find the \(y\) or \(f(x)\) values coming out.

\(x\) \(-2\) \(-1\) \(0\) \(1\) \(2\)
\(f(x)\) \(0.25^{-2}\) \(0.25^{-1}\) \(0.25^{0}\) \(0.25^{1}\) \(0.25^{2}\)
\(y\) \(16\) \(4\) \(1\) \(0.25\) \(0.0625\)

Since the point \((-2,\,16)\) is larger than the rest, it will not be placed on the graph for the sake of space — but it gives you an idea of how quickly the function is increasing.

While it looks like the graph will touch the \(x\)-axis, this is not the case because of the horizontal asymptote at \(y = 0\) — our graph gets infinitely close to that line but never actually touches it.

2. \(g(x) = -3^{x+1}\)

\(x\) \(-2\) \(-1\) \(0\) \(1\) \(2\)
\(g(x)\) \(-3^{-2+1}\) \(-3^{-1+1}\) \(-3^{0+1}\) \(-3^{1+1}\) \(-3^{2+1}\)
\(y\) \(-\tfrac{1}{3}\) \(-1\) \(-3\) \(-9\) \(-27\)

Notice how this graph is below the \(x\)-axis. This occurred because the graph was reflected over the \(x\)-axis due to the negative in front of our base.

3. \(h(x) = 4^x - 2\)

\(x\) \(-2\) \(-1\) \(0\) \(1\) \(2\)
\(h(x)\) \(4^{-2}-2\) \(4^{-1}-2\) \(4^{0}-2\) \(4^{1}-2\) \(4^{2}-2\)
\(y\) \(-1.9375\) \(-1.75\) \(-1\) \(2\) \(14\)

Looking at this graph we can see that the entire graph was shifted down by the \(-2\) in the equation, which means that our asymptote is also shifted down two units to \(y = -2\).

4. \(k(x) = 2^{-x}\)

\(x\) \(-2\) \(-1\) \(0\) \(1\) \(2\)
\(k(x)\) \(2^{+2}\) \(2^{+1}\) \(2^{0}\) \(2^{-1}\) \(2^{-2}\)
\(y\) \(4\) \(2\) \(1\) \(0.5\) \(0.25\)

Notice how this graph looks very similar to the graph of our first example. Negative exponents and fractional bases have the same effect on the graph — they both reflect the graph over the \(y\)-axis.

Applications

Now that we have the graphs of exponential functions worked out, let's look at how exponential functions can be applied to the real world.

One of the more common or familiar applications using exponential functions are exponential growth type examples. The one we are going to talk about specifically today is used primarily in investments. The compound interest formula is used in investing to calculate the future value of an account with so much invested at a given interest rate, where the interest can be calculated multiple times a year.

Compound Interest

\(\displaystyle A = P\!\left(1 + \frac{r}{n}\right)^{nt}\)

Where:

  • \(P\) — is the initial investment.
  • \(r\) — is the interest rate as a decimal.
  • \(n\) — is the number of times interest is compounded per year.
  • \(t\) — is the time in years.

In this equation, \(A\) is the value in the account after \(t\) years.

Since \(t\) is in the exponent's place, that makes this equation an exponential function. With compound interest the amount in the account grows exponentially.

Example

Sally inherited a large sum of money when her grandfather died, and is looking to invest the money into an account that compounds interest quarterly at a rate of 6.5%. If Sally inherited \(\$20{,}000\), how much money will she have in 1, 5, 10, and \(t\) years?

Solution

First we will need to derive the formula using the pieces from the problem. Sally invests \(P = \$20{,}000\). The interest rate is 6.5%, so as a decimal \(r = 0.065\). Compounded quarterly means \(n = 4\). Putting it all together:

\[A = \$20{,}000\!\left(1 + \frac{0.065}{4}\right)^{4t} = \$20{,}000\,(1.01625)^{4t}\]

Don't forget to use order of operations — you must evaluate \((1.01625)^{4t}\) before multiplying by \(\$20{,}000\). Now let's evaluate the expression for each value of \(t\):

\(t\) Expression \(A\)
\(1\) \(\$20{,}000\,(1.01625)^{4(1)} = \$20{,}000\,(1.01625)^{4}\) \(\$21{,}332.03\)
\(5\) \(\$20{,}000\,(1.01625)^{4(5)} = \$20{,}000\,(1.01625)^{20}\) \(\$27{,}608.40\)
\(10\) \(\$20{,}000\,(1.01625)^{4(10)} = \$20{,}000\,(1.01625)^{40}\) \(\$38{,}111.18\)
\(t\) \(\$20{,}000\,(1.01625)^{4t}\) \(\$20{,}000\,(1.01625)^{4t}\)

Looking at the table we can see that the account does not increase by the same amount each year. It starts slowly at first and then jumps to larger amounts over more years. Our last row is a general expression so that we can find the value for any number of years.

Occasionally a person may want to calculate the interest placed into an account using continuous compounding. In this type of equation, we calculate the interest using

\[A = Pe^{rt}\]

instead. This formula brings us closer to an exponential growth model, which we will talk about later in the chapter.

We saw in the graphs that sometimes our graphs will increase exponentially (such as example 3) or they will decrease exponentially (as seen in examples 1 and 4). Both are useful for application purposes.

Example

A documentary revisited in 2019 the nuclear accident that occurred in Chernobyl in 1986. During the explosion, toxic radioactive gas such as plutonium was released into the air and spanned an area of over hundreds of square miles. The model

\[P = 10\!\left(\frac{1}{2}\right)^{\!\frac{t}{24{,}100}}\]

represents the amount of plutonium that remains in the area after \(t\) years, given an initial amount of 10 pounds was leaked. Based on this information, sketch the graph of the amount of plutonium left after \(t\) years, and find how much plutonium would be left in the year 2025.

Solution

To graph this equation we create a table just as we did earlier in the chapter.

Years (\(t\)) \(0\) \(10\) \(20\) \(30\) \(40\)
Plutonium (lbs) \(10\) \(9.9971\) \(9.9942\) \(9.9914\) \(9.9885\)

As we can see in the table, it is barely changing after 40 years, which means to graph it we'd need much larger numbers to see the whole picture. Using technology, the graph looks like:

From the graph we can see that it will take a very long time for the amount of plutonium to decay. But we also know that since this is an exponential function, there will actually never be zero plutonium in Chernobyl.

To find the amount of plutonium left in the year 2025, we first identify how many years have passed since 1986:

\[2025 - 1986 = 39 \text{ years}\]

Then substitute \(t = 39\) into the equation:

\[P = 10\!\left(\frac{1}{2}\right)^{\!\frac{39}{24{,}100}} = 10\!\left(\frac{1}{2}\right)^{0.0016182573} = 10\,(0.9988789384) \approx 9.9888 \text{ lbs}\]
This suggests that in the year 2025 there will still be approximately 9.99 pounds of plutonium active in Chernobyl. Later in this chapter we will learn how to determine how long it would take until a specific amount of plutonium remained — even though we know there will always be some.
