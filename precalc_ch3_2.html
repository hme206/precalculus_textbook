CH 3.2 – Logarithmic Functions and Their Graphs

In the previous section we learned about exponential functions and we discussed briefly that they are one-to-one. If you recall from Chapter 1, a function is one-to-one if its inverse is also a function. The inverse of an exponential function is a logarithmic function with base b.

Logarithmic Function

Assume that \(x > 0\) and base \(b > 0\) where \(b \neq 1\). Then the logarithmic function base \(b\) is:

\(y = \log_b x \iff x = b^y\)

\(y = \log_b x\) is read as "log base \(b\) of \(x\)".

Recall that in the previous section we also had a special character for the natural base. In logarithmic functions we also have a special notation for that situation — we call it the Natural Logarithm, such that

\[\log_e x = \ln x\]

Instead of saying "log base \(e\) of \(x\)" we simply call this the "natural log of \(x\)." By default we work in a base-10 system, which means that when we write \(\log\) without a base, it is understood to be \(\log_{10}\).

Example

Evaluate the following expressions.

  1. \(\log_2 32\)
  2. \(\ln 5\)
  3. \(\log_5 25\)
  4. \(\log 150\)

Solution

  1. To begin, we can write the function as an exponential function, since we cannot enter \(\log_2 32\) directly into a scientific calculator:

    \[\log_2 32 \rightarrow 32 = 2^y\]

    We need to ask: two to what power gives 32? Since \(2 \times 2 \times 2 \times 2 \times 2 = 32\), we get \(y = 5\).

  2. This one is simple enough to plug into the calculator by entering "ln" followed by 5:

    \[\ln 5 = 1.609437912\]

  3. Once again we rewrite as an exponential function:

    \[\log_5 25 \rightarrow 25 = 5^y\]

    We should know that \(5^2 = 25\), thus \(y = 2\).

  4. We can evaluate this by substituting it into the calculator. Since no base is written, we assume base 10 by default. Pressing the "log" key followed by 150 gives:

    \[\log 150 = 2.176091259\]

Most of that was fairly straightforward, but we are going to build upon those ideas — and the conversion to an exponential function will be crucial when graphing logarithmic functions.

Before we get into graphing logarithmic functions, let's discuss some special properties about them.

Properties of Logarithms

  1. \(\log_b 1 = 0\), since \(b^0 = 1\)
  2. \(\log_b b = 1\), since \(b^1 = b\)
  3. \(\log_b b^x = x\) and \(b^{\log_b x} = x\)    (Inverse Property)
  4. If \(\log_b x = \log_b y\), then \(x = y\)    (One-to-One Property)

Example

Simplify the following expressions.

  1. \(\log_5 5\)
  2. \(\ln 1\)
  3. \(\log_6 6^7\)
  4. \(\log_4(x+2) = \log_4(2x)\)

Solution

  1. This follows by Property 2. Thus \(\log_5 5 = 1\).

  2. The properties that apply for logarithms are the same as the properties of natural logarithms, thus this follows Property 1: \(\ln 1 = 0\).

  3. This is an example of Property 3: \(\log_6 6^7 = 7\).

  4. This is an example of Property 4. Since \(\log_4(x+2) = \log_4(2x)\), then \(x + 2 = 2x\). Subtracting \(x\) from both sides gives \(x = 2\).

Graphs of Logarithmic Functions

When it comes to graphing logarithms we have to take a somewhat backwards approach. As we've mentioned several times, logarithms are the inverses of exponential functions. This is important because it essentially flips our values around. When evaluating logarithms, even of whole numbers, the answer most often comes out as a long decimal. Since graphing functions with long decimal inputs is difficult, we need to employ a backwards approach. But before we get to that, let's look at the properties of logarithmic graphs.

Notice how the domain and range are the opposite of the domain and range of the exponential function base \(b\). This is because they are inverse functions. The exponential function reflects over the \(y\)-axis and the logarithmic function reflects over the \(x\)-axis. These are property traits that are important — take note of the slight differences between an exponential and a logarithmic function, as they play important roles for each other.

When graphing logarithmic functions it is important to note that they have vertical asymptotes — if the graph is transformed left or right, the asymptote moves with it. To graph logarithmic functions we:

  1. Convert the logarithm to an exponential function using the property that \(\log_b x = y \iff b^y = x\).
  2. Create a table and plug in \(y\)-values to find \(x\)-values. (Notice how we are plugging in for \(y\), not \(x\).)
  3. Plot the graph using the points and the vertical asymptote.

Example

Graph each of the logarithms below.

  1. \(f(x) = \log_2 x\)
  2. \(g(x) = \log_5(x-1)\)
  3. \(h(x) = -2 - \log_3 x\)
  4. \(k(x) = \ln(x+2)\)

Solution

1. \(f(x) = \log_2 x\)

First, convert \(f(x)\) to an exponential function:

\[f(x) = \log_2 x \iff 2^y = x\]

Next, create a table where we choose \(y\)-values to plug into the exponential function to find the \(x\)-values. Remember that the points are still \((x, y)\) — do not make your table backwards or you will confuse yourself.

\(2^y = x\) \(y\) \((x,\, y)\)
\(2^{-2}\) \(-2\) \((0.25,\,-2)\)
\(2^{-1}\) \(-1\) \((0.5,\,-1)\)
\(2^{0}\) \(0\) \((1,\,0)\)
\(2^{1}\) \(1\) \((2,\,1)\)
\(2^{2}\) \(2\) \((4,\,2)\)

Plot the points, draw the vertical asymptote at \(x = 0\), and connect with a smooth curve.

2. \(g(x) = \log_5(x-1)\)

Convert \(g(x)\) to an exponential function:

\[\begin{aligned} g(x) = \log_5(x-1) &\iff 5^y = x - 1 \\ 5^y + 1 &= x \end{aligned}\]
\(5^y + 1 = x\) \(y\) \((x,\, y)\)
\(5^{-1}+1\) \(-1\) \((1.2,\,-1)\)
\(5^{0}+1\) \(0\) \((2,\,0)\)
\(5^{1}+1\) \(1\) \((6,\,1)\)
\(5^{2}+1\) \(2\) \((26,\,2)\)
\(5^{3}+1\) \(3\) \((126,\,3)\)

Plot the points and draw the vertical asymptote. Note that the graph shifted 1 unit to the right, so the asymptote also shifts to \(x = 1\).

3. \(h(x) = -2 - \log_3 x\)

Convert \(h(x)\) to an exponential function:

\[\begin{aligned} y &= -2 - \log_3 x \\ y + 2 &= -\log_3 x \\ -y - 2 &= \log_3 x \iff 3^{-y-2} = x \end{aligned}\]
\(3^{-y-2} = x\) \(y\) \((x,\, y)\)
\(3^{-(-4)-2} = 3^{2}\) \(-4\) \((9,\,-4)\)
\(3^{-(-3)-2} = 3^{1}\) \(-3\) \((3,\,-3)\)
\(3^{-(-2)-2} = 3^{0}\) \(-2\) \((1,\,-2)\)
\(3^{-(-1)-2} = 3^{-1}\) \(-1\) \((0.33,\,-1)\)
\(3^{-(0)-2} = 3^{-2}\) \(0\) \((0.11,\,0)\)

Plot the points, draw the vertical asymptote at \(x = 0\), and connect with a smooth curve.

Notice how this graph was reflected over the \(x\)-axis and then shifted down two whole units.

4. \(k(x) = \ln(x+2)\)

Convert \(k(x)\) to an exponential function:

\[\begin{aligned} k(x) = \ln(x+2) &\iff e^y = x + 2 \\ e^y - 2 &= x \end{aligned}\]
\(e^y - 2 = x\) \(y\) \((x,\, y)\)
\(e^{-2} - 2\) \(-2\) \((-1.86,\,-2)\)
\(e^{-1} - 2\) \(-1\) \((-1.63,\,-1)\)
\(e^{0} - 2\) \(0\) \((-1,\,0)\)
\(e^{1} - 2\) \(1\) \((0.718,\,1)\)
\(e^{2} - 2\) \(2\) \((5.389,\,2)\)

Plot the points and draw the vertical asymptote. Note that the graph shifted 2 units to the left, so the asymptote moves to \(x = -2\).

Applications

Just like with exponential functions, logarithms can also be applied to the real world.

Example

The percent of households in the United States that do not have a land-line telephone service from the years 2005 to 2014 can be approximated by the model

\[P(t) = -3.42 + 1.297(t)\ln(t)\]

where \(t\) is the number of years since 2000. Approximate the number of households that only have a cell phone in the years 2010 and 2020.

Solution

First, find how many years since 2000 each target year represents:

\[2010 - 2000 = 10 \qquad \text{and} \qquad 2020 - 2000 = 20\]

We evaluate the expression at \(t = 10\) and \(t = 20\):

\[\begin{aligned} P(10) &= -3.42 + 1.297(10)\ln(10) \\ &= -3.42 + 12.97(2.302585093) \\ &\approx 26.44 \end{aligned}\]

This suggests that in 2010 roughly 26% of all households had only a cell phone and no land-line.

\[\begin{aligned} P(20) &= -3.42 + 1.297(20)\ln(20) \\ &= -3.42 + 25.94(2.995732274) \\ &\approx 74.29 \end{aligned}\]

This suggests that in 2020 roughly 74% of all households had only a cell phone and no land-line. Notice how much those numbers increased in just 10 years.
