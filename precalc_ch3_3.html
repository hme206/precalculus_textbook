CH 3.3 – Properties of Logarithms

They say you have to learn to crawl before you can walk. In mathematics it is no different. We have to introduce ideas in smaller steps so that in later processes you can apply them. In this section we are going to cover a lot of properties and how they are applied. While it may seem pointless at first, everything in this section is building to assist you in the section that comes next.

Most calculators, as I am sure you've come to see, only have limited logarithm keys. Unless you have a newer graphing calculator, your calculator most likely only has the log key for common logarithms and the ln key for natural logarithms. However, we will from time to time need to evaluate logarithmic functions of other bases. This is where the Change-of-Base Formula comes into play.

Change-of-Base Formula

If we allow \(b\) and \(x\) to be positive real numbers such that \(b \neq 1\), then we can change any logarithm into a common logarithm or natural logarithm.

Base \(a\) \[\log_b x = \frac{\log_a x}{\log_a b}\]
Base 10 \[\log_b x = \frac{\log x}{\log b}\]
Base \(e\) \[\log_b x = \frac{\ln x}{\ln b}\]

Example

Using the change-of-base formula, convert the following to the common base logarithm, then evaluate the expressions.

  1. \(\log_4 30\)
  2. \(\log_3 15\)

Solution

\[\log_4 30 = \frac{\log 30}{\log 4} \approx 2.45\]
\[\log_3 15 = \frac{\log 15}{\log 3} \approx 2.46\]

Example

Using the change-of-base formula, convert the following to the natural base logarithm, then evaluate the expressions.

  1. \(\log_5 35\)
  2. \(\log_6 15\)

Solution

\[\log_5 35 = \frac{\ln 35}{\ln 5} \approx 2.21\]
\[\log_6 15 = \frac{\ln 15}{\ln 6} \approx 1.51\]

These are not the only properties that allow us to rewrite logarithms in other forms. We also have the following properties that allow us to either expand a logarithm or condense a logarithm — both of which are useful when solving logarithmic and exponential equations, which we will cover in the next section.

Properties of Logarithms

Allow \(b\) to be any positive real number except \(1\), and allow \(n\), \(u\), and \(v\) to be any positive real numbers. Then:

  1. Product Rule: \(\log_b(uv) = \log_b u + \log_b v\)
  2. Quotient Rule: \(\log_b\!\left(\dfrac{u}{v}\right) = \log_b u - \log_b v\)
  3. Power Rule: \(\log_b u^n = n\log_b u\)

Product Rule

Example

Apply the Product Rule to the examples below.

  1. \(\log_3 10\)
  2. \(\log_x 3y\)

Solution

\[\log_3 10 = \log_3(5 \cdot 2) = \log_3 5 + \log_3 2\]
\[\log_x 3y = \log_x(3 \cdot y) = \log_x 3 + \log_x y\]

Quotient Rule

Example

Apply the Quotient Rule to the examples below.

  1. \(\log_3\dfrac{2}{27}\)
  2. \(\log_x\dfrac{y}{2}\)

Solution

\[\log_3\frac{2}{27} = \log_3 2 - \log_3 27\]
\[\log_x\frac{y}{2} = \log_x y - \log_x 2\]

Power Rule

Example

Apply the Power Rule to the examples below.

  1. \(\log_3 b^4\)
  2. \(\log_x y^z\)

Solution

\[\log_3 b^4 = 4\log_3 b\]
\[\log_x y^z = z\log_x y\]

Expanding Logarithmic Expressions

Now that we've looked at each property individually, let's apply multiple rules to a single expression.

Example

Expand each logarithmic expression.

  1. \(\log_5 5x^2y\)
  2. \(\ln\!\sqrt{\dfrac{3x}{y^2}}\)

Solution

1. \(\log_5 5x^2y\)
\[\log_5 5x^2y = \log_5 5 + \log_5 x^2 + \log_5 y\]
Product Rule
\[= \log_5 5 + 2\log_5 x + \log_5 y\]
Power Rule
\[= 1 + 2\log_5 x + \log_5 y\]
Simplify \((\log_5 5 = 1)\)
2. \(\ln\!\sqrt{\dfrac{3x}{y^2}}\)
\[\ln\sqrt{\frac{3x}{y^2}} = \ln\!\left(\frac{3x}{y^2}\right)^{\!\frac{1}{2}}\]
Definition of Radical
\[= \frac{1}{2}\ln\!\left(\frac{3x}{y^2}\right)\]
Power Rule
\[= \frac{1}{2}\!\left(\ln 3x - \ln y^2\right)\]
Quotient Rule
\[= \frac{1}{2}\!\left(\ln 3 + \ln x - \ln y^2\right)\]
Product Rule
\[= \frac{1}{2}\!\left(\ln 3 + \ln x - 2\ln y\right)\]
Power Rule
\[= \frac{1}{2}\ln 3 + \frac{1}{2}\ln x - (2)\tfrac{1}{2}\ln y\]
Distributive Property
\[= \frac{1}{2}\ln 3 + \frac{1}{2}\ln x - \ln y\]
Simplify

Condensing Logarithmic Expressions

Example

Condense each logarithmic expression.

  1. \(\dfrac{1}{2}\log x + 3\log(x+2) - \log y\)
  2. \(3 + 2\log_x y - \dfrac{1}{4}\log_x z\)

Solution

1. \(\dfrac{1}{2}\log x + 3\log(x+2) - \log y\)
\[= \log\sqrt{x} + \log(x+2)^3 - \log y\]
Power Rule
\[= \log\!\left[\sqrt{x}\,(x+2)^3\right] - \log y\]
Product Rule
\[= \log\frac{\sqrt{x}\,(x+2)^3}{y}\]
Quotient Rule
2. \(3 + 2\log_x y - \dfrac{1}{4}\log_x z\)
\[= 3\log_x x + 2\log_x y - \frac{1}{4}\log_x z\]
Property of Logarithms \((\log_b b = 1)\)
\[= \log_x x^3 + \log_x y^2 - \log_x \sqrt[4]{z}\]
Power Rule
\[= \log_x(x^3 y^2) - \log_x \sqrt[4]{z}\]
Product Rule
\[= \log_x\frac{x^3 y^2}{\sqrt[4]{z}}\]
Quotient Rule

When it comes to expanding and condensing logarithms you have to think of them as puzzles and work in very small steps. Just like with a puzzle, you can't put together the center until you've assembled the outer shell. Do not try to combine too many steps at once — you're likely to miss something.
