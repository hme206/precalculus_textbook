CH 3.4 – Solving Exponential and Logarithmic Equations

By this point in the chapter you should have a decent understanding of exponential and logarithmic functions, their properties, and the connection between the two functions. It should come as no surprise that exponential and logarithmic functions are the inverses of each other — after all, they are one-to-one. Recall from Chapter 1 that two functions \(f\) and \(g\) are inverses of each other if both compositions \(f(g(x))\) and \(g(f(x))\) equal \(x\). This is an important concept, as it leads directly to our ability to solve these equations — along with the properties learned in the previous section.

In Section 3.2 we discussed the one-to-one property for logarithmic functions:

\[\log_a x = \log_a y \iff x = y\]

It should be no surprise that we have the same property for exponential functions:

\[b^x = b^y \iff x = y\]

This is an extremely useful property because it allows us to access the variables in each equation.

The One-to-One Property

Example

Solve the equations below using the one-to-one property.

  1. \(\log_2(x+1) = \log_2(-3x+5)\)
  2. \(\ln(x^2+x-2) = \ln(x+2)\)
  3. \(2^{(x+2)} = 2^{4x}\)
  4. \(e^{-x^2} = e^{-3x-4}\)

Solution

1. \(\log_2(x+1) = \log_2(-3x+5)\)

Since both sides are log base 2, we can drop the \(\log_2\) and set the arguments equal, then solve for \(x\):

\[\begin{aligned} x + 1 &= -3x + 5 \\ 4x + 1 &= 5 \\ 4x &= 4 \\ x &= 1 \end{aligned}\]

2. \(\ln(x^2+x-2) = \ln(x+2)\)

Since \(\ln\) appears on both sides with the same base, we drop it and solve the resulting equation:

\[\begin{aligned} x^2 + x - 2 &= x + 2 \\ x^2 - 2 &= 2 \\ x^2 &= 4 \\ x &= \pm\sqrt{4} = \pm 2 \end{aligned}\]

It is important to remember that you cannot take the logarithm of a negative number or zero. That is why we must check each solution.

Check \(x = -2\):
\[\begin{aligned} \ln\!\left((-2)^2+(-2)-2\right) &= \ln\!\left((-2)+2\right) \\ \ln(4-2-2) &= \ln(0) \\ \ln(0) &= \ln(0) \\ \text{undefined} &= \text{undefined} \end{aligned}\]
Check \(x = 2\):
\[\begin{aligned} \ln\!\left((2)^2+(2)-2\right) &= \ln\!\left((2)+2\right) \\ \ln(4) &= \ln(4) \checkmark \end{aligned}\]

This solution checks out. \(x = 2\) is valid.

\(x = -2\) is an extraneous solution. Since \(\ln(0)\) is undefined, \(x = -2\) must be rejected. The only solution is \(x = 2\).

3. \(2^{(x+2)} = 2^{4x}\)

Both sides have the same base, so we set the exponents equal and solve:

\[\begin{aligned} x + 2 &= 4x \\ 2 &= 3x \\ x &= \frac{2}{3} \end{aligned}\]

4. \(e^{-x^2} = e^{-3x-4}\)

Remember that \(e\) is a base like any other — it is a fixed number; we use the symbol to avoid writing all the decimal places. Set the exponents equal and solve:

\[\begin{aligned} -x^2 &= -3x - 4 \\ 0 &= x^2 - 3x - 4 \\ 0 &= (x-4)(x+1) \end{aligned}\]
\[\begin{aligned} x - 4 &= 0 \\ x &= 4 \end{aligned}\]
\[\begin{aligned} x + 1 &= 0 \\ x &= -1 \end{aligned}\]

With exponential equations we don't have to be wary of negative solutions, as we can evaluate both positive and negative exponents. However, it is always a good habit to check your answer. Both \(x = 4\) and \(x = -1\) are valid solutions.

All of this is great when the one-to-one property can be applied, but that isn't always the case. What if we wanted to solve \(\log_2(x+2) + 2 = 4\)? We can't simply drop the \(\log_2\). The same is true for an exponential equation such as \(2^{x+2} = 3\). In order to solve equations like these we need to "log" or "base" both sides, then apply our inverse properties — and if logarithmic, the power rule. Let's tackle these situations one at a time, starting with exponential equations.

Exponential Equations

When solving exponential equations that don't follow the one-to-one property, we first isolate the exponential piece and then "log" or "ln" both sides to solve.

Example

Solve each of the exponential equations below.

  1. \(e^{x+5} = 3\)
  2. \(2^x + 3 = 7\)
  3. \(2(3^{x+1}) - 4 = 12\)

Solution

1. \(e^{x+5} = 3\)
By the inverse property we know that \(\ln(e^x) = x\), meaning \(\ln\) is the inverse of \(e\). We solve by placing \(\ln\) on both sides:
\[e^{x+5} = 3\]
Write the equation
\[\textcolor{red}{\ln}(e^{x+5}) = \textcolor{red}{\ln} 3\]
Take \(\ln\) of both sides
\[x + 5 = \ln 3\]
Apply inverse property
\[x = \ln 3 - 5 \approx -3.9\]
Solve for \(x\)
2. \(2^x + 3 = 7\)
While we could use the inverse property with a log of the matching base, we prefer to work in base 10. We first isolate the exponential, then "log" both sides and apply the power rule:
\[2^x + 3 = 7\]
Write the equation
\[2^x = 4\]
Isolate the exponential
\[\textcolor{red}{\log}(2^x) = \textcolor{red}{\log} 4\]
"Log" both sides
\[\textcolor{red}{x}\log 2 = \log 4\]
Power Rule — bring exponent down
\[x = \frac{\log 4}{\log 2} = 2\]
Solve with calculator
3. \(2(3^{x+1}) - 4 = 12\)
\[2(3^{x+1}) - 4 = 12\]
Write the equation
\[2(3^{x+1}) = 16\]
Isolate the exponential term
\[3^{x+1} = 8\]
Divide both sides by 2
\[\textcolor{red}{\log}(3^{x+1}) = \textcolor{red}{\log} 8\]
"Log" both sides
\[\textcolor{red}{(x+1)}\log 3 = \log 8\]
Power Rule — bring exponent down
\[x\log 3 + \log 3 = \log 8\]
Distribute \(\log 3\)
\[x\log 3 = \log 8 - \log 3\]
Isolate the \(x\) term
\[x = \frac{\log 8 - \log 3}{\log 3} \approx 0.89\]
Solve with calculator

Depending on your calculator, you may be able to enter that last expression directly. If your calculator only has a single-line display, you could apply the Quotient Rule to combine:

\[\log 8 - \log 3 = \log\!\left(\frac{8}{3}\right)\]

making it much easier to enter.

Logarithmic Equations

Now let's look at how we'd solve logarithmic equations that can't be solved using the one-to-one property. We'll start with the ones that just require a bit of manipulation using the product and quotient rules.

Example

Solve the logarithmic equations below.

  1. \(\log_3(5x-1) = \log_3(x+7) + \log_3 2\)
  2. \(\log_5(x+2) - \log_5 x = \log_5 6\)
  3. \(\ln(x+1) - \ln 4 = \ln(x+2) - \ln 3\)

Solution

1. \(\log_3(5x-1) = \log_3(x+7) + \log_3 2\)
While all log terms share the same base, we cannot simply drop the log when multiple terms are present. We must first condense using the product rule:
\[\log_3(5x-1) = \log_3(x+7) + \log_3 2\]
Write the equation
\[\log_3(5x-1) = \log_3\!\bigl[(x+7)(2)\bigr]\]
Product Rule — condense right side
\[(5x-1) = (x+7)(2)\]
One-to-One Property
\[5x - 1 = 2x + 14\]
Expand
\[3x = 15\]
Solve for \(x\)
\[x = 5\]
2. \(\log_5(x+2) - \log_5 x = \log_5 6\)
The minus sign on the left indicates the Quotient Rule:
\[\log_5(x+2) - \log_5 x = \log_5 6\]
Write the equation
\[\log_5\!\left(\frac{x+2}{x}\right) = \log_5 6\]
Quotient Rule — condense left side
\[\frac{x+2}{x} = \frac{6}{1}\]
One-to-One Property
\[6x = 1(x+2)\]
Cross-multiply
\[6x = x + 2\]
Expand
\[5x = 2\]
Solve for \(x\)
\[x = \frac{2}{5}\]
3. \(\ln(x+1) - \ln 4 = \ln(x+2) - \ln 3\)
This one must be condensed on both sides simultaneously:
\[\ln(x+1) - \ln 4 = \ln(x+2) - \ln 3\]
Write the equation
\[\ln\frac{x+1}{4} = \ln\frac{x+2}{3}\]
Quotient Rule — condense both sides
\[\frac{x+1}{4} = \frac{x+2}{3}\]
One-to-One Property
\[3(x+1) = 4(x+2)\]
Cross-multiply
\[3x + 3 = 4x + 8\]
Expand
\[x = -5\]
Solve for \(x\)
Check: Substituting \(x = -5\) requires evaluating \(\ln(-5+1) = \ln(-4)\), which is undefined. Therefore this equation has no solution.

Next let's look at logarithmic equations that cannot be solved with condensing and the one-to-one property alone. With these types of equations we need to apply a "base" to each side to use the inverse property \(b^{\log_b x} = x\). Select the base that matches the logarithmic function in the equation.

Example

Solve the following logarithmic equations.

  1. \(\log_2(3x) = 4\)
  2. \(2\ln(3x+1) = 2\)
  3. \(2\log_3 2x - \log_3 5 = 3\)

Solution

1. \(\log_2(3x) = 4\)
The log is base 2, so we apply a base of 2 to each side:
\[\log_2(3x) = 4\]
Write the equation
\[\textcolor{red}{2}^{\log_2(3x)} = \textcolor{red}{2}^4\]
Apply base 2 to each side
\[3x = 16\]
Inverse Property
\[x = \frac{16}{3}\]
Solve for \(x\)
2. \(2\ln(3x+1) = 2\)
First isolate the \(\ln\), then apply base \(e\):
\[2\ln(3x+1) = 2\]
Write the equation
\[\ln(3x+1) = 1\]
Isolate the \(\ln\)
\[e^{\ln(3x+1)} = e^1\]
Apply base \(e\) to each side
\[3x + 1 = e\]
Inverse Property
\[3x = e - 1\]
Subtract 1
\[x = \frac{e-1}{3} \approx 0.57\]
Solve for \(x\)
3. \(2\log_3 2x - \log_3 5 = 3\)
First apply the Power Rule, then the Quotient Rule, then apply a base of 3:
\[2\log_3 2x - \log_3 5 = 3\]
Write the equation
\[\log_3(2x)^2 - \log_3 5 = 3\]
Power Rule
\[\log_3\!\left(\frac{4x^2}{5}\right) = 3\]
Quotient Rule
\[\textcolor{red}{3}^{\log_3\!\left(\frac{4x^2}{5}\right)} = \textcolor{red}{3}^3\]
Apply base 3 to each side
\[\frac{4x^2}{5} = 27\]
Inverse Property
\[4x^2 = 135\]
Cross-multiply
\[x^2 = \frac{135}{4}\]
Divide by 4
\[x = \pm\frac{\sqrt{135}}{2} \approx \pm 5.809\]
Take square root
The negative solution \(x \approx -5.809\) must be rejected because you cannot take the logarithm of a negative number. The only valid solution is \(x \approx 5.809\).

As can be seen, there is not just one way to solve either of these types of equations. It requires the use of multiple methods and properties — but in most cases they follow the same solving principles learned in basic algebra.

Applications

While it is important to be able to evaluate exponential and logarithmic functions, it is equally important to be able to solve them. For example, what if you were investing money and wanted to know how many years you'd need to leave it in an account to reach a specific amount? Instead of using trial-and-error, we can apply the methods just covered. A few models we will use are:

Mathematical Models

  1. Exponential Growth: \(y = a(e^{bx})\) where \(b > 0\).
  2. Exponential Decay: \(y = a(e^{-bx})\) where \(b > 0\).
  3. Logarithmic Models: \(y = a + b\log x\) and \(y = a + b\ln x\).

Example

Scientists found in a study that a specific bacteria triples each hour. If the sample started with 10 bacteria, how long will it take for the bacteria to reach a level of 1,000?

Solution

Since we are talking about rapid growth, this is an exponential growth model. We identify the initial value \(a = 10\) bacteria, giving us

\[y = 10e^{bx}\]

where \(x\) is hours and \(y\) is the number of bacteria after \(x\) hours. We find \(b\) using the fact that at \(x = 1\), the population triples to \(y = 30\):

\[\begin{aligned} 30 &= 10e^{b(1)} \\ 3 &= e^b \\ \ln 3 &= \ln(e^b) \\ b &= \ln 3 \end{aligned}\]

Substituting back into our model:

\[y = 10e^{x\ln 3} = 10(3^x)\]

Now we solve for the time \(x\) when \(y = 1{,}000\):

\[\begin{aligned} 1{,}000 &= 10(3^x) \\ 100 &= 3^x \\ \textcolor{red}{\log} 100 &= \textcolor{red}{\log}(3^x) \\ \log 100 &= x\log 3 \\ x &= \frac{\log 100}{\log 3} \approx 4.19 \end{aligned}\]

It will take approximately 4.2 hours for the bacteria to reach a population of 1,000.

Example

The half-life of Carbon-14 is 5,730 years. If an object has a Carbon-14 level of 15, how many years will it take for the level to reach 1?

Solution

This is an exponential decay model. The initial amount is \(a = 15\), giving us

\[y = 15e^{-bx}\]

We find \(b\) using the half-life: at \(x = 5{,}730\), the amount is \(y = 0.5 \times 15 = 7.5\):

\[\begin{aligned} 7.5 &= 15e^{-b(5730)} \\ 0.5 &= e^{-5730b} \\ \ln(0.5) &= \ln(e^{-5730b}) \\ \ln(0.5) &= -5730b \\ b &= \frac{\ln(0.5)}{-5730} \\ b &\approx 1.209 \times 10^{-4} = 0.0001209 \end{aligned}\]

Substituting into our model: \(y = 15e^{-0.0001209x}\).

Now we solve for \(x\) when \(y = 1\):

\[\begin{aligned} 1 &= 15e^{-0.0001209x} \\ \tfrac{1}{15} &= e^{-0.0001209x} \\ \ln\!\left(\tfrac{1}{15}\right) &= \ln\!\left(e^{-0.0001209x}\right) \\ \ln\!\left(\tfrac{1}{15}\right) &= -0.0001209x \\ x &= \frac{\ln(1/15)}{-0.0001209} \approx 22{,}386.5 \end{aligned}\]

It will take roughly 22,386.5 years before the Carbon-14 level in the object reaches 1.

Example

The magnitude \(R\) of earthquakes is measured using the Richter scale, and the intensity \(I\) can be modeled by

\[R = \log\frac{I}{I_0}\]

where the minimum intensity \(I_0 = 1\). What is the intensity of an earthquake that measured \(R = 7.9\) on the Richter scale?

Solution

Set up the equation with \(R = 7.9\) and \(I_0 = 1\):

\[7.9 = \log\frac{I}{1} = \log I\]

Then solve for \(I\) by applying base 10 to both sides:

\[\begin{aligned} 7.9 &= \log I \\ 10^{7.9} &= 10^{\log I} \\ I &= 79{,}431{,}823.47 \end{aligned}\]

The earthquake would have an intensity of approximately 79,431,823 — for those who may not know, that is an extremely intense earthquake.

These are not the only types of applications for these functions, but all others follow the same approach. For example, we could revisit the Chernobyl example from Section 3.1 and use our new skills to find how many years it would take until Chernobyl had less than 1 pound of plutonium remaining.

Exponential decay models are also frequently used in carbon dating for identifying the age of fossils and artifacts — but that is only one of many applications. The number of real-world situations that exponential and logarithmic functions describe is remarkable, and they are a necessity in the majority of the sciences.
