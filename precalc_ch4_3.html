CH 4.3 – Solving Systems by Elimination

In the previous section we learned to solve systems of equations by graphing and substitution. In this section we will discuss how we solve systems using the elimination method (Addition Method). This method lends itself to linear systems.

When using the elimination method, what you are looking to do, is try to perform operations on either one equation or both equations in a way that when you add the two together, you eliminate one of your variables.

Example

Solve the system of equations below by using the elimination method.

  1. \(x + y = 6\)
    \(x - y = 12\)
  2. \(2x - 4y = -7\)
    \(5x + y = -1\)
  3. \(3x + 2y = 4\)
    \(9x + 6y = 3\)
  4. \(7x + 8y = 6\)
    \(-0.14x - 0.16y = -0.12\)

Solution

System 1

To solve this first example we first need to decide which variable we want to eliminate. Try to first look to see if any variable had opposite signs. In this example our \(y\) have different signs in each equation, so we will eliminate that variable. Next we have to determine what we'd need to multiply each equation by to have the same coefficient in front of \(y\), luckily for this question they are already the same coefficient with different signs, meaning we can just add the questions together.

\(x\) \(+\) \(y\) \(=\) \(6\)
\(+\) \(x\) \(-\) \(y\) \(=\) \(12\)
\(2x\) \(=\) \(18\)
\(x\) \(=\) \(\dfrac{18}{2}\)
\(x\) \(=\) \(9\)

Now, that we've found \(x\) we take that value and plug it into one of the two equations, the equation that you plug into doesn't really matter. Just as long as you end up with a \(y\) value that makes the statements true. If we plugged it into the first equation:

\[\begin{aligned} \textcolor{red}{9} + y &= 6 \\ y &= -3 \end{aligned}\]
Giving us the solution of \((9, -3)\), making this a consistent system. Consistent

System 2

We start this the same way, first select the variable you'll eliminate, we are going to eliminate \(y\) again because of the fact that one is positive and the other is negative. Then we have to decide what we will multiply the second equation by to have the opposite coefficient of the first equation. In this case it would be four:

\(2x\) \(-\) \(4y\) \(=\) \(-7\) \(\rightarrow\) \(2x\) \(-\) \(4y\) \(=\) \(-7\)
\(+\) \(4(5x\) \(+\) \(y\) \(=\) \(-1)\) \(\rightarrow\) \(20x\) \(+\) \(4y\) \(=\) \(-4\)
\(22x\) \(=\) \(-11\)
\(x\) \(=\) \(\dfrac{-11}{22}\)
\(x\) \(=\) \(-\dfrac{1}{2}\)

Plug that back in to find \(y\), once again the equation doesn't matter you could even use the equation that was the result of multiplying the second equation by 4 if you really wanted to. Try to evaluate which of the equations would be the simplest to use, notice how the first equation multiplies \(x\) by two, if we multiply our \(x\) value by two it will eliminate the fraction in it:

\[\begin{aligned} 2\!\left(\textcolor{red}{-\tfrac{1}{2}}\right) - 4y &= -7 \\ -1 - 4y &= -7 \\ -4y &= -6 \\ y &= \frac{-6}{-4} = \frac{3}{2} \end{aligned}\]
Giving us the solution of \(\left(-\dfrac{1}{2},\, \dfrac{3}{2}\right)\), which once again is a consistent system. Consistent

System 3

Take the same approach as the others:

\(-3(3x\) \(+\) \(2y\) \(=\) \(4)\) \(\rightarrow\) \(-9x\) \(-\) \(6y\) \(=\) \(-12\)
\(+\) \(9x\) \(+\) \(6y\) \(=\) \(3\) \(\rightarrow\) \(9x\) \(+\) \(6y\) \(=\) \(3\)
\(0\) \(=\) \(-9\)
In this example notice how we have a statement that is false, the left hand and right hand side are not the same. If you recall from the previous section, this meant that the system had no solution. The same is still true, this example has no solution, and would be inconsistent. Inconsistent

System 4

For our last example the first thing we'd want to do is eliminate any decimal or fractional values to do that, we're going to multiply the entire second equation by 100 to move the decimal place two places which would give us an equation of \(-14x - 16y = -12\). From here we can then continue our method of elimination:

\(2(7x\) \(+\) \(8y\) \(=\) \(6)\) \(\rightarrow\) \(14x\) \(+\) \(16y\) \(=\) \(12\)
\(+\) \(-14x\) \(-\) \(16y\) \(=\) \(-12\) \(\rightarrow\) \(-14x\) \(-\) \(16y\) \(=\) \(-12\)
\(0\) \(=\) \(0\)

Once again recall from the previous section that when you end up with a true statement meaning the left hand and right hand side are the same, that tells us that we have infinite solutions. But, remember we can't just say infinite solutions we have to put that in terms of one of the variables. We are going to put this one in terms of \(x\) that means we'd need to solve one equation for \(y\):

\[\begin{aligned} 7x + 8y &= 6 \\ 8y &= 6 - 7x \\ y &= \frac{6}{8} - \frac{7}{8}x \\ y &= \frac{3}{4} - \frac{7}{8}x \end{aligned}\]

Thus giving us the solution of:

\[\left(x,\; \frac{3}{4} - \frac{7}{8}x\right)\]

In each of these examples we only had to manipulate the equations minimally to make them work, sometimes more work will be required. It is possible that you'll have to multiply each equation by different values in order to eliminate a variable. This method is important because of the fact it will be used in the next section.

While it doesn't matter which method you use to solve equations, each method lends itself to certain characteristics of how the equations are set up. Typically speaking if in a system of equations one equation is already solved or mostly solved for a variable we tend to use the substitution method. Where as, if a system is set up where both the \(x\) and \(y\) values are on the same side of the equation and the constant on the opposite, we use the elimination method. But, there is no rule that says you have to do that. If you want to only solve systems using one method go for it, however, it will cause you more work in the long run.

Applications

We've mentioned in this chapter that systems of equations have a number of applications to the real world, one of the more common applications is the example of supply and demand. In these types of applications typically analysts want to find the equilibrium point, this is the point at which supply and demand are the same. Think about it, this is an important concept in product production. A company doesn't want to produce thousands of products when their demand equation says they'll only sell hundreds of the product. That company would lose money in that case.

Supply and demand is not the only way we use systems of equations in the real-world. There are many more and we will look at a few different examples.

Example

A company hires a financial analyst to determine how many of their new product they should produce. The analyst found that the company demand is \(p = 180 - 0.00001x\) and their supply equation is \(p = 90 + 0.00002x\). Where \(p\) is the price per unit, and \(x\) is the number of units they can sell. How many units should the company have made? What is their price to break-even?

Solution

For this example we are trying to find the equilibrium point. Notice that each of the equations are solved for the same variable that means we can set them equal to each other and solve for \(x\):

\[\begin{aligned} 180 - 0.00001x &= 90 + 0.00002x \\ 180 &= 90 + 0.00003x \\ 90 &= 0.00003x \\ \frac{90}{0.00003} &= x \\ 3{,}000{,}000 &= x \end{aligned}\]

This means that the company should make three million units to break-even, and they should sell the units for:

\[\begin{aligned} p &= 180 - 0.00001(\textcolor{red}{3{,}000{,}000}) \\ p &= \$150.00 \end{aligned}\]
This means our equilibrium point is \((3{,}000{,}000,\; \$150)\). You can check this solution by plugging it back into the equations and verifying that they both work out.

Example

Carrie is taking a Chemistry class, in her lab section she needs to create a certain chemical mixture. If thirty liters of 40% acid solution is obtained by mixing 25% solution with a 50% solution. How much of each solution does she need to make the 40% solution?

Solution

When it comes to application questions where equations are not given, it is useful to create a table to help arrange your information:

Acid Amount Solution
\(40\%\) \(30\) \(0.4(30) = 12\)
\(25\%\) \(x\) \(0.25x\)
\(50\%\) \(y\) \(0.5y\)

Since we don't know how much of each solution we need we use variables. It doesn't matter what you label those variables as, you can use any variable you want. From the table we can conclude that we have the system of:

\[\begin{cases} x + y = 30 \\ 0.25x + 0.5y = 12 \end{cases}\]

We know that we need to take that second equation and make everything whole numbers, to do that we'd need to multiply by \(100\): \((0.25x + 0.5y = 12) \rightarrow 25x + 50y = 1200\). Next we'd solve our system of equations using which ever method we want. We are going to use elimination though, since that is how this system is set up.

\(-25(x\) \(+\) \(y\) \(=\) \(30)\) \(\rightarrow\) \(-25x\) \(-\) \(25y\) \(=\) \(-750\)
\(+\) \(25x\) \(+\) \(50y\) \(=\) \(1200\) \(\rightarrow\) \(25x\) \(+\) \(50y\) \(=\) \(1200\)
\(25y\) \(=\) \(450\)
\(y\) \(=\) \(18\)
This means we need \(18\) liters of \(50\%\) solution, and \(x + 18 = 30 \rightarrow x = 12\) liters of \(25\%\) solution to make \(30\) liters of \(40\%\) acid solution.

Example

Carl received a bonus check last year for \(\$32,000\), and instead of spending his money he invested part of his money into a bond that paid \(5.75\%\) interest, and part into a CD that paid \(6.25\%\) interest. Carl earned a total income of \(\$1,900\) from both investments. How much did he invest into each account?

Solution

In order to answer this question we first have to recall how to calculate simple interest, \(I = prt\) where \(p\) is the amount of the principal investment, \(r\) is the interest rate as a decimal and \(t\) is the time in years. Once again we will create a table to help us set up the problem:

Account Amount Interest
Bond (\(5.75\%\)) \(x\) \(0.0575x\)
CD (\(6.25\%\)) \(y\) \(0.0625y\)
Total \(\$32,000\) \(\$1,900\)

Once again since we don't know how much he is investing in each account we need to use variables to set up the equations of:

\[\begin{cases} x + y = 32000 \\ 0.0575x + 0.0625y = 1900 \end{cases}\]

Since we have decimal values we know that we will have to get rid of those, by multiplying the second equation by \(10{,}000\): \((0.0575x + 0.0625y = 1900) \rightarrow 575x + 625y = 19{,}000{,}000\). Remember we need a zero for each decimal place that we need to move. Now, we are ready to solve our system of equations.

\(-575(x\) \(+\) \(y\) \(=\) \(32000)\) \(\rightarrow\) \(-575x\) \(-\) \(575y\) \(=\) \(-18{,}400{,}000\)
\(+\) \(575x\) \(+\) \(625y\) \(=\) \(19{,}000{,}000\) \(\rightarrow\) \(575x\) \(+\) \(625y\) \(=\) \(19{,}000{,}000\)
\(50y\) \(=\) \(600{,}000\)
\(y\) \(=\) \(12{,}000\)
Carl invested \(\$12,000\) into the CD, and \(x + 12000 = 32000 \rightarrow x = \$20,000\) in the bond. Remember it is always a good choice to go back and double check your answer.
