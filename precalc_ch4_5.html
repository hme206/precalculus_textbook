CH 4.5 – Partial Fractions

In chapter 2 we discussed rational functions, their graphs and inequalities. We know that a rational function is a function that has a polynomial in both the numerator and the denominator. In this section we are going to discuss something known as partial fraction decomposition, and what that does is, it allows us to write our rational function as the sum of rational expressions instead of one full one. For example:

\[\frac{x+7}{x^2-x-6} = \frac{2}{x-3} + \frac{-1}{x+2}\]

The left hand side is our rational function, where the right hand side is our partial fraction decomposition of that function. If you were to add together the two rational expressions on the right, it would be the same as what is on the left. Essentially it allows us to undo, addition of rational expressions.

The process for partial fraction decomposition can be a bit complicated when put into words, so we will be sure to do several examples. But first the process:

Process: Partial Fraction Decomposition

  1. If the fraction is improper, divide the numerator by the denominator and write the resulting quotient as \(P(x) + \dfrac{r(x)}{d(x)}\) where \(P(x)\) is the polynomial quotient, and \(r(x)\) is the remaining polynomial. Just like in Chapter 2, with dividing polynomials.
  2. Factor the denominator.
  3. For each factor using the letters "A, B, C, ...", write the rational function as a sum of its linear factors with numerator values of "A, B, C, ...". \[\frac{A}{x-a_1} + \frac{B}{x-a_2} + \frac{C}{x-a_3} \cdots\]
  4. Solve the linear factors using systems of equations.
  5. Re-write the solution replacing the "A, B, C, ..." with the numbers found in the previous step.

Now the way you set up step 3, differs depending on if you have linear factors or quadratic factors. We are only going to look at linear factors in this course. But note, in your future you could see non-linear factors.

Example

Write the partial fraction decomposition of

\[\frac{x+7}{x^2-x-6}\]

Solution

  1. This rational expression isn't improper, thus we can go to the next step.
  2. Factor the denominator: \[\frac{x+7}{x^2-x-6} = \frac{x+7}{(x-3)(x+2)}\]
  3. Expand factors, notice how both factors are linear that means we can write this as: \[\frac{x+7}{(x-3)(x+2)} = \frac{A}{(x-3)} + \frac{B}{(x+2)}\]

    If you wrote the A and B over the opposite factors, that is completely fine, the answer will still work out.

  4. Solve — To do this we have to recall a couple rules, such as you have to have common denominators to add two fractions, and how to find the lowest common multiple (LCM) for the denominator. Looking at these two rational expressions, they don't have anything in common in the denominator, meaning we can just multiply each one top and bottom by the opposite denominator:

    \[\frac{A\textcolor{red}{(x+2)}}{(x-3)\textcolor{red}{(x+2)}} + \frac{B\textcolor{red}{(x-3)}}{(x+2)\textcolor{red}{(x-3)}} = \frac{Ax+2A}{(x-3)(x+2)} + \frac{Bx-3B}{(x-3)(x+2)}\] \[= \frac{Ax+2A+Bx-3B}{(x-3)(x+2)}\]

    Using the combined rational, we will set up a system of equations using the pieces in the numerator. At this point we can disregard the denominator for a minute. You take the terms in the numerator that are common and set them equal to the portion of the original numerator that they had in common to get a system of equations.

    Our first equation would be the one created by the terms that contain an \("x"\):

    \[Ax + Bx = x\]

    Now take this equation and divide both sides by \("x"\) to reduce it and get:

    \[A + B = 1\]

    Our second equation would be created by our constant terms:

    \[2A - 3B = 7\]

    This would give us the system of:

    \[\begin{cases} A + B = 1 \\ 2A - 3B = 7 \end{cases}\]

    Using whichever method you prefer solve the system of equations:

    \(-2(A + B = 1)\) \(\rightarrow\) \(-2A - 2B = -2\)
    \(+\) \(2A - 3B = 7\) \(\rightarrow\) \(2A - 3B = 7\)
    \(-5B = 5\)
    \(B = -1\)

    Back substitution to find \("A"\):

    \[A + B = 1 \rightarrow A + (-1) = 1 \rightarrow A = 2\]
  5. Now we are ready to re-write our solution: \[\frac{A}{(x-3)} + \frac{B}{(x+2)} = \frac{2}{(x-3)} + \frac{-1}{(x+2)}\] \[= \frac{2}{(x-3)} - \frac{1}{(x+2)}\]

Example

Express as the sum of linear factors

\[\frac{x+6}{(x-2)(x+2)(x-3)}\]

Solution

  1. Once again we can skip this step, because it isn't an improper fraction.
  2. We can also skip this step, since the denominator is already factored.
  3. Our first step with this problem would be to write it as the sum of our linear factors which would be: \[\frac{A}{x+2} + \frac{B}{x-2} + \frac{C}{x-3}\] Notice how for each factor we have a different variable in the numerator.

  4. Now we need to find our LCM again and combine all of our linear factors:

    \[\frac{A(\textcolor{red}{(x-2)(x-3)})}{(x+2)(\textcolor{red}{(x-2)(x-3)})} + \frac{B(\textcolor{red}{(x+2)(x-3)})}{(x-2)(\textcolor{red}{(x+2)(x-3)})} + \frac{C(\textcolor{red}{(x-2)(x+2)})}{(x-3)(\textcolor{red}{(x-2)(x+2)})}\] \[= \frac{A(x^2-x-6)}{(x-2)(x+2)(x-3)} + \frac{B(x^2-5x+6)}{(x-2)(x+2)(x-3)} + \frac{C(x^2-4)}{(x-2)(x+2)(x-3)}\] \[= \frac{Ax^2-Ax-6A}{(x-2)(x+2)(x-3)} + \frac{Bx^2-5Bx+6B}{(x-2)(x+2)(x-3)} + \frac{Cx^2-4C}{(x-2)(x+2)(x-3)}\]

    Just like we did in the previous problem break them up into different equations using their terms and setting it equal to the original numerator. The equation we'd get from our squared terms would be:

    \[Ax^2 + Bx^2 + Cx^2 = 0x^2\]

    from our \("x"\) terms:

    \[-Ax - 5Bx = 1x\]

    and our constant terms:

    \[-6A + 6B - 4C = 6\]

    We'd divide the first equation by \(x^2\) and our second equation by \(x\) to end up with the system:

    \[\begin{cases} A + B + C = 0 \\ -A - 5B = 1 \\ -6A + 6B - 4C = 6 \end{cases}\]

    Now we're ready to solve the system of equations:

    \(4(A + B + C = 0)\) \(\rightarrow\) \(4A + 4B + 4C = 0\)
    \(+\) \(-6A + 6B - 4C = 6\) \(\rightarrow\) \(-6A + 6B - 4C = 6\)
    \(-2A + 10B = 6\)
    \(-2A + 10B = 6\) \(\rightarrow\) \(-2A + 10B = 6\)
    \(+\) \(-2(-A - 5B = 1)\) \(\rightarrow\) \(2A + 10B = -2\)
    \(20B = 4\)
    \(B = \dfrac{4}{20} = \dfrac{1}{5}\)

    Back substitution to find \("A"\):

    \[\begin{aligned} -A - 5B &= 1 \\ -A - 5\!\left(\frac{1}{5}\right) &= 1 \\ -A - 1 &= 1 \\ -A &= 2 \\ A &= -2 \end{aligned}\]

    then \("C"\):

    \[\begin{aligned} A + B + C &= 0 \\ -2 + \frac{1}{5} + C &= 0 \\ -\frac{9}{5} + C &= 0 \\ C &= \frac{9}{5} \end{aligned}\]
  5. Now we're ready to write our final answer: \[\frac{-2}{x+2} + \frac{\dfrac{1}{5}}{x-2} + \frac{\dfrac{9}{5}}{x-3}\] \[= \frac{-2}{x+2} + \frac{1}{5(x-2)} + \frac{9}{5(x-3)}\]

Both of these are examples when you have just singular linear factors. However if you have repeat linear factors the process changes just slightly.

Repeat Linear Factors

A repeat linear factor is a linear factor with a multiplicity greater than one. It would be something like \(x^2 = x(x)\) or something like \((x-1)^3 = (x-1)(x-1)(x-1)\) each of those are a linear factor that has a multiplicity greater than one.

Example

Write the partial fraction decomposition of

\[\frac{3x}{(x-3)^2}\]

Solution

For this problem we can skip the first couple steps and start at step 3 where we write this as the sum of partial fractions. However, this time it changes slightly because we have a repeat factor — this would give us:

\[\frac{A}{x-3} + \frac{B}{(x-3)^2}\]

You have to write a partial fraction for each power of \(x\). Meaning if \((x-3)^3\) was our denominator then we'd need one more partial fraction with \("C"\) as the numerator. Now we're ready to go ahead to step 4 and solve this to find \(A\) and \(B\):

\[\frac{A(\textcolor{red}{x-3})}{(x-3)(\textcolor{red}{x-3})} + \frac{B}{(x-3)^2}\]

This gives us the system:

\[\begin{cases} A = 3 \\ -3A + B = 0 \end{cases}\] \[\begin{aligned} -3(3) + B &= 0 \\ -9 + B &= 0 \\ B &= 9 \end{aligned}\]
Giving us the partial fraction decomposition: \[\frac{3}{x-3} + \frac{9}{(x-3)^2}\]

Example

Write the partial fraction decomposition of

\[\frac{x^4+x^3+x+4}{x^3+x^2}\]

Solution

  1. We can see that in this one we actually need to divide, since it gives us an improper fraction.

    \[\require{enclose} \begin{array}{r} x + 0 \\[-3pt] x^3+x^2 \enclose{longdiv}{x^4+x^3+0x^2+x+4} \\[-3pt] \underline{-(x^4+x^3)\phantom{{}+0x^2+x+4}} \\[-3pt] 0x^2 + x + 4 \end{array}\]

    That means we'd end up with the equation:

    \[x + \frac{x+4}{x^3+x^2}\]

    We'd only need to find the partial fractions for the rational piece.

  2. Factor the denominator completely: \[\frac{x+4}{x^2(x+1)}\] This time our repeat linear factor is our \(x\).
  3. Write as partial fractions: \[\frac{A}{x} + \frac{B}{x^2} + \frac{C}{x+1}\]

  4. Solve our partial fraction:

    \[\frac{A(\textcolor{red}{x(x+1)})}{x(\textcolor{red}{x(x+1)})} + \frac{B(\textcolor{red}{x+1})}{x^2(\textcolor{red}{x+1})} + \frac{C(\textcolor{red}{x^2})}{(x+1)(\textcolor{red}{x^2})}\] \[= \frac{Ax^2+Ax}{x^2(x+1)} + \frac{Bx+B}{x^2(x+1)} + \frac{Cx^2}{x^2(x+1)}\]

    This gives us the system:

    \[\begin{cases} A + C = 0 \\ A + B = 1 \\ B = 4 \end{cases}\]

    Back Substitution:

    \[\begin{aligned} A + B &= 1 \\ A + 4 &= 1 \\ A &= -3 \end{aligned}\]
    \[\begin{aligned} A + C &= 0 \\ -3 + C &= 0 \\ C &= 3 \end{aligned}\]
  5. Re-write the partial fraction: \[\frac{-3}{x} + \frac{4}{x^2} + \frac{3}{x+1}\]

When it comes to partial fractions try to think about un-packaging something. You're trying to pull the pieces back apart again. You can always check your work, by adding the fractions back together. It should give you the original fraction.
