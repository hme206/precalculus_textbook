CH 6.3 – Solving Trigonometric Equations

In previous sections we solved some basic equations involving the trigonometric functions. Below we summarize the techniques we've employed thus far. Note that we use the neutral letter \(u\) as the argument of each circular function for generality.

Strategies for Solving Basic Equations Involving Trigonometric Functions

  • To solve \(\cos(u) = c\) or \(\sin(u) = c\) for \(-1 \leq c \leq 1\), first solve for \(u\) in the interval \([0, 2\pi)\) and add integer multiples of the period \(2\pi\). If \(c < -1\) or \(c > 1\), there are no real solutions.
  • To solve \(\sec(u) = c\) or \(\csc(u) = c\) for \(c \leq -1\) or \(c \geq 1\), convert to cosine or sine, respectively, and solve as above. If \(-1 < c < 1\), there are no real solutions.
  • To solve \(\tan(u) = c\) for any real number \(c\), first solve for \(u\) in the interval \(\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)\) and add integer multiples of the period \(\pi\).
  • To solve \(\cot(u) = c\) for \(c \neq 0\), convert to tangent and solve as above. If \(c = 0\), the solution to \(\cot(u) = 0\) is \(u = \dfrac{\pi}{2} + \pi k\) for integers \(k\).

Using the above guidelines, we can comfortably solve \(\sin(x) = \frac{1}{2}\) and find the solution \(x = \frac{\pi}{6} + 2\pi k\) or \(x = \frac{5\pi}{6} + 2\pi k\) for integers \(k\). How do we solve something like \(\sin(3x) = \frac{1}{2}\)? Since this equation has the form \(\sin(u) = \frac{1}{2}\), we know the solutions take the form \(u = \frac{\pi}{6} + 2\pi k\) or \(u = \frac{5\pi}{6} + 2\pi k\) for integers \(k\). Since the argument of sine here is \(3x\), we have \(3x = \frac{\pi}{6} + 2\pi k\) or \(3x = \frac{5\pi}{6} + 2\pi k\) for integers \(k\). To solve for \(x\), we divide both sides of these equations by \(3\), and obtain \(x = \frac{\pi}{18} + \frac{2\pi}{3} k\) or \(x = \frac{5\pi}{18} + \frac{2\pi}{3}k\) for integers \(k\). This is the technique employed in the example below.

Example 1

Solve the following equations and check your answers analytically. List the solutions which lie in the interval \([0, 2\pi)\).

  1. \(\cos(2x) = -\dfrac{\sqrt{3}}{2}\)
  2. \(\csc\!\left(\dfrac{1}{3}x - \pi\right) = \sqrt{2}\)
  3. \(\cot(3x) = 0\)
  4. \(\sec^{2}(x) = 4\)
  5. \(\tan\!\left(\dfrac{x}{2}\right) = -3\)
  6. \(\sin(2x) = 0.87\)

Solution

1. The solutions to \(\cos(u) = -\dfrac{\sqrt{3}}{2}\) are \(u = \dfrac{5\pi}{6} + 2\pi k\) or \(u = \dfrac{7\pi}{6} + 2\pi k\) for integers \(k\). Since the argument of cosine here is \(2x\), this means \(2x = \dfrac{5\pi}{6} + 2\pi k\) or \(2x = \dfrac{7\pi}{6} + 2\pi k\) for integers \(k\). Solving for \(x\) gives \(x = \dfrac{5\pi}{12} + \pi k\) or \(x = \dfrac{7\pi}{12} + \pi k\) for integers \(k\). To check these answers analytically, we substitute them into the original equation. For any integer \(k\) we have

\[ \begin{array}{rclr} \cos\!\left(2\!\left[\dfrac{5\pi}{12} + \pi k\right]\right) &=& \cos\!\left(\dfrac{5\pi}{6} + 2\pi k\right) & \\[6pt] &=& \cos\!\left(\dfrac{5\pi}{6}\right) & \text{(the period of cosine is } 2\pi\text{)} \\[6pt] &=& -\dfrac{\sqrt{3}}{2} & \end{array} \]

Similarly, we find \(\cos\!\left(2\!\left[\dfrac{7\pi}{12} + \pi k\right]\right) = \cos\!\left(\dfrac{7\pi}{6} + 2\pi k\right) = \cos\!\left(\dfrac{7\pi}{6}\right) = -\dfrac{\sqrt{3}}{2}\). To determine which of our solutions lie in \([0,2\pi)\), we substitute integer values for \(k\). The solutions we keep come from the values of \(k = 0\) and \(k = 1\) and are \(x = \dfrac{5\pi}{12}\), \(\dfrac{7\pi}{12}\), \(\dfrac{17\pi}{12}\) and \(\dfrac{19\pi}{12}\).

2. Since this equation has the form \(\csc(u) = \sqrt{2}\), we rewrite this as \(\sin(u) = \dfrac{\sqrt{2}}{2}\) and find \(u = \dfrac{\pi}{4} + 2\pi k\) or \(u = \dfrac{3\pi}{4} + 2\pi k\) for integers \(k\). Since the argument of cosecant here is \(\left(\dfrac{1}{3}x - \pi\right)\),

\[ \frac{1}{3}x - \pi = \frac{\pi}{4} + 2\pi k \qquad \text{or} \qquad \frac{1}{3}x - \pi = \frac{3\pi}{4} + 2\pi k \]

To solve \(\dfrac{1}{3}x - \pi = \dfrac{\pi}{4} + 2\pi k\), we first add \(\pi\) to both sides:

\[ \frac{1}{3}x = \frac{\pi}{4} + 2\pi k + \pi \]

A common error is to treat the \(2\pi k\) and \(\pi\) terms as "like" terms and try to combine them when they are not. We can, however, combine the \(\pi\) and \(\dfrac{\pi}{4}\) terms to get

\[ \frac{1}{3}x = \frac{5\pi}{4} + 2\pi k \]

We now finish by multiplying both sides by \(3\) to get

\[ x = 3\!\left(\frac{5\pi}{4} + 2\pi k\right) = \frac{15\pi}{4} + 6\pi k \]

Solving the other equation, \(\dfrac{1}{3}x - \pi = \dfrac{3\pi}{4} + 2\pi k\), produces \(x = \dfrac{21\pi}{4} + 6\pi k\) for integers \(k\). To check the first family of answers, we substitute, combine like terms, and simplify:

\[ \begin{array}{rclr} \csc\!\left(\dfrac{1}{3}\!\left[\dfrac{15\pi}{4} + 6\pi k\right] - \pi\right) &=& \csc\!\left(\dfrac{5\pi}{4} + 2\pi k - \pi\right) & \\[6pt] &=& \csc\!\left(\dfrac{\pi}{4} + 2\pi k\right) & \\[6pt] &=& \csc\!\left(\dfrac{\pi}{4}\right) & \text{(the period of cosecant is } 2\pi\text{)} \\[4pt] &=& \sqrt{2} & \end{array} \]

The family \(x = \dfrac{21\pi}{4} + 6\pi k\) checks similarly. Despite having infinitely many solutions, we find that none of them lie in \([0,2\pi)\). To verify this graphically, we use a reciprocal identity to rewrite the cosecant as a sine and we find that \(y = \dfrac{1}{\sin\!\left(\frac{1}{3}x - \pi\right)}\) and \(y = \sqrt{2}\) do not intersect at all over the interval \([0,2\pi)\).

3. Since \(\cot(3x) = 0\) has the form \(\cot(u) = 0\), we know \(u = \dfrac{\pi}{2} + \pi k\), so, in this case, \(3x = \dfrac{\pi}{2} + \pi k\) for integers \(k\). Solving for \(x\) yields \(x = \dfrac{\pi}{6} + \dfrac{\pi}{3}k\). Checking our answers, we get

\[ \begin{array}{rclr} \cot\!\left(3\!\left[\dfrac{\pi}{6} + \dfrac{\pi}{3}k\right]\right) &=& \cot\!\left(\dfrac{\pi}{2} + \pi k\right) & \\[6pt] &=& \cot\!\left(\dfrac{\pi}{2}\right) & \text{(the period of cotangent is } \pi\text{)} \\[6pt] &=& 0 & \end{array} \]

As \(k\) runs through the integers, we obtain six answers corresponding to \(k = 0\) through \(k = 5\), which lie in \([0,2\pi)\): \(x = \dfrac{\pi}{6}\), \(\dfrac{\pi}{2}\), \(\dfrac{5\pi}{6}\), \(\dfrac{7\pi}{6}\), \(\dfrac{3\pi}{2}\) and \(\dfrac{11\pi}{6}\). To confirm these graphically, we must be careful. On many calculators, there is no function button for cotangent. We choose to use the quotient identity \(\cot(3x) = \dfrac{\cos(3x)}{\sin(3x)}\).

4. The complication in solving an equation like \(\sec^{2}(x) = 4\) comes not from the argument of secant, which is just \(x\), but rather the fact that secant is being squared. To get this equation to look like one of the standard forms, we extract square roots to get \(\sec(x) = \pm 2\). Converting to cosines, we have \(\cos(x) = \pm\dfrac{1}{2}\).

For \(\cos(x) = \dfrac{1}{2}\), we get \(x = \dfrac{\pi}{3} + 2\pi k\) or \(x = \dfrac{5\pi}{3} + 2\pi k\) for integers \(k\). For \(\cos(x) = -\dfrac{1}{2}\), we get \(x = \dfrac{2\pi}{3} + 2\pi k\) or \(x = \dfrac{4\pi}{3} + 2\pi k\) for integers \(k\).

If we take a step back and think of these families of solutions geometrically, we see we are finding the measures of all angles with a reference angle of \(\dfrac{\pi}{3}\). As a result, these solutions can be combined and we may write our solutions as \(x = \dfrac{\pi}{3} + \pi k\) and \(x = \dfrac{2\pi}{3} + \pi k\) for integers \(k\). To check the first family of solutions, we note that, depending on the integer \(k\), \(\sec\!\left(\dfrac{\pi}{3} + \pi k\right)\) doesn't always equal \(\sec\!\left(\dfrac{\pi}{3}\right)\). However, it is true that for all integers \(k\), \(\sec\!\left(\dfrac{\pi}{3} + \pi k\right) = \pm\sec\!\left(\dfrac{\pi}{3}\right) = \pm 2\). As a result,

\[ \begin{array}{rclr} \sec^{2}\!\left(\dfrac{\pi}{3} + \pi k\right) &=& \left(\pm\sec\!\left(\dfrac{\pi}{3}\right)\right)^{2} & \\[6pt] &=& (\pm 2)^{2} & \\[6pt] &=& 4 & \end{array} \]

The same holds for the family \(x = \dfrac{2\pi}{3} + \pi k\). The solutions which lie in \([0,2\pi)\) come from the values \(k = 0\) and \(k = 1\), namely \(x = \dfrac{\pi}{3}\), \(\dfrac{2\pi}{3}\), \(\dfrac{4\pi}{3}\) and \(\dfrac{5\pi}{3}\).

5. The equation \(\tan\!\left(\dfrac{x}{2}\right) = -3\) has the form \(\tan(u) = -3\), whose solution is \(u = \arctan(-3) + \pi k\). Hence, \(\dfrac{x}{2} = \arctan(-3) + \pi k\), so \(x = 2\arctan(-3) + 2\pi k\) for integers \(k\). To check, we note

\[ \begin{array}{rclr} \tan\!\left(\dfrac{2\arctan(-3) + 2\pi k}{2}\right) &=& \tan\!\left(\arctan(-3) + \pi k\right) & \\[6pt] &=& \tan\!\left(\arctan(-3)\right) & \text{(the period of tangent is } \pi\text{)} \\[6pt] &=& -3 & \end{array} \]

To determine which of our answers lie in the interval \([0,2\pi)\), we first need to get an idea of the value of \(2\arctan(-3)\). Since \(-3 < 0\), it follows that \(-\dfrac{\pi}{2} < \arctan(-3) < 0\). Multiplying through by \(2\) gives \(-\pi < 2\arctan(-3) < 0\). We are now in a position to argue which of the solutions \(x = 2\arctan(-3) + 2\pi k\) lie in \([0,2\pi)\).

For \(k = 0\), we get \(x = 2\arctan(-3) < 0\), so we discard this answer and all answers \(x = 2\arctan(-3) + 2\pi k\) where \(k < 0\).

Next, we turn our attention to \(k = 1\) and get \(x = 2\arctan(-3) + 2\pi\). Starting with the inequality \(-\pi < 2\arctan(-3) < 0\), we add \(2\pi\) and get \(\pi < 2\arctan(-3) + 2\pi < 2\pi\). This means \(x = 2\arctan(-3) + 2\pi\) lies in \([0,2\pi)\). Advancing \(k\) to \(2\) produces \(x = 2\arctan(-3) + 4\pi\). Once again, we get from \(-\pi < 2\arctan(-3) < 0\) that \(3\pi < 2\arctan(-3) + 4\pi < 4\pi\). Since this is outside the interval \([0,2\pi)\), we discard \(x = 2\arctan(-3) + 4\pi\) and all solutions of the form \(x = 2\arctan(-3) + 2\pi k\) for \(k > 2\).

6. To solve \(\sin(2x) = 0.87\), we first note that it has the form \(\sin(u) = 0.87\), which has the family of solutions \(u = \arcsin(0.87) + 2\pi k\) or \(u = \pi - \arcsin(0.87) + 2\pi k\) for integers \(k\). Since the argument of sine here is \(2x\), we get \(2x = \arcsin(0.87) + 2\pi k\) or \(2x = \pi - \arcsin(0.87) + 2\pi k\), which gives \(x = \dfrac{1}{2}\arcsin(0.87) + \pi k\) or \(x = \dfrac{\pi}{2} - \dfrac{1}{2}\arcsin(0.87) + \pi k\) for integers \(k\). To check,

\[ \begin{array}{rclr} \sin\!\left(2\!\left[\dfrac{1}{2}\arcsin(0.87) + \pi k\right]\right) &=& \sin\!\left(\arcsin(0.87) + 2\pi k\right) & \\[6pt] &=& \sin\!\left(\arcsin(0.87)\right) & \text{(the period of sine is } 2\pi\text{)} \\[6pt] &=& 0.87 & \end{array} \]

For the family \(x = \dfrac{\pi}{2} - \dfrac{1}{2}\arcsin(0.87) + \pi k\), we get

\[ \begin{array}{rclr} \sin\!\left(2\!\left[\dfrac{\pi}{2} - \dfrac{1}{2}\arcsin(0.87) + \pi k\right]\right) &=& \sin\!\left(\pi - \arcsin(0.87) + 2\pi k\right) & \\[6pt] &=& \sin\!\left(\pi - \arcsin(0.87)\right) & \text{(the period of sine is } 2\pi\text{)} \\[6pt] &=& \sin\!\left(\arcsin(0.87)\right) & \text{(\(\sin(\pi - t) = \sin(t)\))} \\[6pt] &=& 0.87 & \end{array} \]

To determine which of these solutions lie in \([0,2\pi)\), we first need to get an idea of the value of \(x = \dfrac{1}{2}\arcsin(0.87)\). By definition, \(0 < \arcsin(0.87) < \dfrac{\pi}{2}\) so that multiplying through by \(\dfrac{1}{2}\) gives us \(0 < \dfrac{1}{2}\arcsin(0.87) < \dfrac{\pi}{4}\). Starting with the family of solutions \(x = \dfrac{1}{2}\arcsin(0.87) + \pi k\), we use the same kind of arguments as above and find only the solutions corresponding to \(k = 0\) and \(k = 1\) lie in \([0,2\pi)\): \(x = \dfrac{1}{2}\arcsin(0.87)\) and \(x = \dfrac{1}{2}\arcsin(0.87) + \pi\).

Next, we move to the family \(x = \dfrac{\pi}{2} - \dfrac{1}{2}\arcsin(0.87) + \pi k\) for integers \(k\). Here, we need to get a better estimate of \(\dfrac{\pi}{2} - \dfrac{1}{2}\arcsin(0.87)\).

From the inequality \(0 < \dfrac{1}{2}\arcsin(0.87) < \dfrac{\pi}{4}\), we first multiply through by \(-1\) and then add \(\dfrac{\pi}{2}\) to get \(\dfrac{\pi}{2} > \dfrac{\pi}{2} - \dfrac{1}{2}\arcsin(0.87) > \dfrac{\pi}{4}\), or \(\dfrac{\pi}{4} < \dfrac{\pi}{2} - \dfrac{1}{2}\arcsin(0.87) < \dfrac{\pi}{2}\). Proceeding with the usual arguments, we find the only solutions which lie in \([0,2\pi)\) correspond to \(k = 0\) and \(k = 1\), namely \(x = \dfrac{\pi}{2} - \dfrac{1}{2}\arcsin(0.87)\) and \(x = \dfrac{3\pi}{2} - \dfrac{1}{2}\arcsin(0.87)\).

All told, we have found four solutions to \(\sin(2x) = 0.87\) in \([0,2\pi)\): \(x = \dfrac{1}{2}\arcsin(0.87)\), \(x = \dfrac{1}{2}\arcsin(0.87) + \pi\), \(x = \dfrac{\pi}{2} - \dfrac{1}{2}\arcsin(0.87)\) and \(x = \dfrac{3\pi}{2} - \dfrac{1}{2}\arcsin(0.87)\).

Each of the problems in the above example featured one trigonometric function. If an equation involves two different trigonometric functions or if the equation contains the same trigonometric function but with different arguments, we will need to use identities and algebra to reduce the equation to the same form as those given in the strategies box above.

Example 2

Solve the following equations and list the solutions which lie in the interval \([0, 2\pi)\).

  1. \(3\sin^{3}(x) = \sin^{2}(x)\)
  2. \(\sec^{2}(x) = \tan(x) + 3\)
  3. \(\cos(2x) = 3\cos(x) - 2\)
  4. \(\cos(3x) = 2 - \cos(x)\)
  5. \(\cos(3x) = \cos(5x)\)
  6. \(\sin(2x) = \sqrt{3}\cos(x)\)
  7. \(\sin(x)\cos\!\left(\dfrac{x}{2}\right) + \cos(x)\sin\!\left(\dfrac{x}{2}\right) = 1\)
  8. \(\cos(x) - \sqrt{3}\sin(x) = 2\)

Solution

1. We resist the temptation to divide both sides of \(3\sin^{3}(x) = \sin^{2}(x)\) by \(\sin^{2}(x)\) and instead gather all of the terms to one side of the equation and factor.

\[ \begin{array}{rclr} 3\sin^{3}(x) &=& \sin^{2}(x) & \\ 3\sin^{3}(x) - \sin^{2}(x) &=& 0 & \\ \sin^{2}(x)\!\left(3\sin(x) - 1\right) &=& 0 & \text{Factor out } \sin^{2}(x). \\ \end{array} \]

We get \(\sin^{2}(x) = 0\) or \(3\sin(x) - 1 = 0\). Solving for \(\sin(x)\), we find \(\sin(x) = 0\) or \(\sin(x) = \dfrac{1}{3}\). The solution to the first equation is \(x = \pi k\), with \(x = 0\) and \(x = \pi\) being the two solutions which lie in \([0,2\pi)\). To solve \(\sin(x) = \dfrac{1}{3}\), we use the arcsine function to get \(x = \arcsin\!\left(\dfrac{1}{3}\right) + 2\pi k\) or \(x = \pi - \arcsin\!\left(\dfrac{1}{3}\right) + 2\pi k\) for integers \(k\). We find the two solutions here which lie in \([0,2\pi)\) to be \(x = \arcsin\!\left(\dfrac{1}{3}\right)\) and \(x = \pi - \arcsin\!\left(\dfrac{1}{3}\right)\).

2. Analysis of \(\sec^{2}(x) = \tan(x) + 3\) reveals two different trigonometric functions, so an identity is in order. Since \(\sec^{2}(x) = 1 + \tan^{2}(x)\), we get

\[ \begin{array}{rclr} \sec^{2}(x) &=& \tan(x) + 3 & \\ 1 + \tan^{2}(x) &=& \tan(x) + 3 & \text{(Since } \sec^{2}(x) = 1 + \tan^{2}(x)\text{.)} \\ \tan^{2}(x) - \tan(x) - 2 &=& 0 & \\ u^{2} - u - 2 &=& 0 & \text{Let } u = \tan(x)\text{.} \\ (u + 1)(u - 2) &=& 0 & \\ \end{array} \]

This gives \(u = -1\) or \(u = 2\). Since \(u = \tan(x)\), we have \(\tan(x) = -1\) or \(\tan(x) = 2\). From \(\tan(x) = -1\), we get \(x = -\dfrac{\pi}{4} + \pi k\) for integers \(k\). To solve \(\tan(x) = 2\), we employ the arctangent function and get \(x = \arctan(2) + \pi k\) for integers \(k\). From the first set of solutions, we get \(x = \dfrac{3\pi}{4}\) and \(x = \dfrac{5\pi}{4}\) as our answers which lie in \([0,2\pi)\). We get \(x = \arctan(2)\) and \(x = \pi + \arctan(2)\) as answers from our second set of solutions which lie in \([0,2\pi)\). Using a reciprocal identity, we rewrite the secant as a cosine and graph \(y = \dfrac{1}{(\cos(x))^{2}}\) and \(y = \tan(x) + 3\) to find the \(x\)-values of the points where they intersect.

3. In the equation \(\cos(2x) = 3\cos(x) - 2\), we have the same circular function, namely cosine, on both sides but the arguments differ. Using the identity \(\cos(2x) = 2\cos^{2}(x) - 1\), we obtain a "quadratic in disguise" and proceed as we have done in the past.

\[ \begin{array}{rclr} \cos(2x) &=& 3\cos(x) - 2 & \\ 2\cos^{2}(x) - 1 &=& 3\cos(x) - 2 & \text{(Since } \cos(2x) = 2\cos^{2}(x) - 1\text{.)} \\ 2\cos^{2}(x) - 3\cos(x) + 1 &=& 0 & \\ 2u^{2} - 3u + 1 &=& 0 & \text{Let } u = \cos(x)\text{.} \\ (2u - 1)(u - 1) &=& 0 & \\ \end{array} \]

This gives \(u = \dfrac{1}{2}\) or \(u = 1\). Since \(u = \cos(x)\), we get \(\cos(x) = \dfrac{1}{2}\) or \(\cos(x) = 1\). Solving \(\cos(x) = \dfrac{1}{2}\), we get \(x = \dfrac{\pi}{3} + 2\pi k\) or \(x = \dfrac{5\pi}{3} + 2\pi k\) for integers \(k\). From \(\cos(x) = 1\), we get \(x = 2\pi k\) for integers \(k\). The answers which lie in \([0,2\pi)\) are \(x = 0\), \(\dfrac{\pi}{3}\), and \(\dfrac{5\pi}{3}\).

4. To solve \(\cos(3x) = 2 - \cos(x)\), we use the same technique as in the previous problem. We know that \(\cos(3x) = 4\cos^{3}(x) - 3\cos(x)\). This transforms the equation into a polynomial in terms of \(\cos(x)\).

\[ \begin{array}{rclr} \cos(3x) &=& 2 - \cos(x) & \\ 4\cos^{3}(x) - 3\cos(x) &=& 2 - \cos(x) & \\ 4\cos^{3}(x) - 2\cos(x) - 2 &=& 0 & \\ 4u^{3} - 2u - 2 &=& 0 & \text{Let } u = \cos(x)\text{.} \\ \end{array} \]

To solve \(4u^{3} - 2u - 2 = 0\), we factor \(4u^{3} - 2u - 2\) into \((u - 1)(4u^{2} + 4u + 2)\). We get either \(u - 1 = 0\) or \(4u^{2} + 4u + 2 = 0\), and since the discriminant of the latter is negative, the only real solution to \(4u^{3} - 2u - 2 = 0\) is \(u = 1\). Since \(u = \cos(x)\), we get \(\cos(x) = 1\), so \(x = 2\pi k\) for integers \(k\). The only solution which lies in \([0,2\pi)\) is \(x = 0\).

5. While we could approach \(\cos(3x) = \cos(5x)\) in the same manner as we did the previous two problems, we choose instead to showcase the utility of the Sum to Product Identities. From \(\cos(3x) = \cos(5x)\), we get \(\cos(5x) - \cos(3x) = 0\), and it is the presence of \(0\) on the right-hand side that indicates a switch to a product would be a good move. Using our Sum to Product identities, we have that

\[ \cos(5x) - \cos(3x) = -2\sin\!\left(\frac{5x+3x}{2}\right)\sin\!\left(\frac{5x-3x}{2}\right) = -2\sin(4x)\sin(x) \]

Hence, the equation \(\cos(5x) = \cos(3x)\) is equivalent to \(-2\sin(4x)\sin(x) = 0\). From this, we get \(\sin(4x) = 0\) or \(\sin(x) = 0\).

Solving \(\sin(4x) = 0\) gives \(x = \dfrac{\pi}{4}k\) for integers \(k\), and the solution to \(\sin(x) = 0\) is \(x = \pi k\) for integers \(k\). The second set of solutions is contained in the first set of solutions, so our final solution to \(\cos(5x) = \cos(3x)\) is \(x = \dfrac{\pi}{4}k\) for integers \(k\). There are eight of these answers which lie in \([0,2\pi)\): \(x = 0\), \(\dfrac{\pi}{4}\), \(\dfrac{\pi}{2}\), \(\dfrac{3\pi}{4}\), \(\pi\), \(\dfrac{5\pi}{4}\), \(\dfrac{3\pi}{2}\) and \(\dfrac{7\pi}{4}\).

6. In examining the equation \(\sin(2x) = \sqrt{3}\cos(x)\), not only do we have different circular functions involved, namely sine and cosine, we also have different arguments to contend with, namely \(2x\) and \(x\). Using the identity \(\sin(2x) = 2\sin(x)\cos(x)\) makes all of the arguments the same and we proceed as we would solving any nonlinear equation — gather all of the nonzero terms on one side of the equation and factor.

\[ \begin{array}{rclr} \sin(2x) &=& \sqrt{3}\cos(x) & \\ 2\sin(x)\cos(x) &=& \sqrt{3}\cos(x) & \text{(Since } \sin(2x) = 2\sin(x)\cos(x)\text{.)} \\ 2\sin(x)\cos(x) - \sqrt{3}\cos(x) &=& 0 & \\ \cos(x)\!\left(2\sin(x) - \sqrt{3}\right) &=& 0 & \\ \end{array} \]

From which we get \(\cos(x) = 0\) or \(\sin(x) = \dfrac{\sqrt{3}}{2}\). From \(\cos(x) = 0\), we obtain \(x = \dfrac{\pi}{2} + \pi k\) for integers \(k\). From \(\sin(x) = \dfrac{\sqrt{3}}{2}\), we get \(x = \dfrac{\pi}{3} + 2\pi k\) or \(x = \dfrac{2\pi}{3} + 2\pi k\) for integers \(k\). The answers which lie in \([0,2\pi)\) are \(x = \dfrac{\pi}{2}\), \(\dfrac{3\pi}{2}\), \(\dfrac{\pi}{3}\) and \(\dfrac{2\pi}{3}\). We graph \(y = \sin(2x)\) and \(y = \sqrt{3}\cos(x)\) and, after some careful zooming, verify our answers.

7. Unlike the previous problem, there seems to be no quick way to get the circular functions or their arguments to match in the equation \(\sin(x)\cos\!\left(\dfrac{x}{2}\right) + \cos(x)\sin\!\left(\dfrac{x}{2}\right) = 1\). If we stare at it long enough, however, we realize that the left-hand side is the expanded form of the sum formula for \(\sin\!\left(x + \dfrac{x}{2}\right)\). Hence, our original equation is equivalent to \(\sin\!\left(\dfrac{3}{2}x\right) = 1\). Solving, we find \(x = \dfrac{\pi}{3} + \dfrac{4\pi}{3}k\) for integers \(k\). Two of these solutions lie in \([0,2\pi)\): \(x = \dfrac{\pi}{3}\) and \(x = \dfrac{5\pi}{3}\).

8. With the absence of double angles or squares, there doesn't seem to be much we can do. However, since the arguments of the cosine and sine are the same, we can rewrite the left-hand side of this equation as a sinusoid. To fit \(f(x) = \cos(x) - \sqrt{3}\sin(x)\) to the form \(A\sin(\omega t + \phi) + B\), we find \(A = 2\), \(B = 0\), \(\omega = 1\) and \(\phi = \dfrac{5\pi}{6}\). Hence, we can rewrite the equation \(\cos(x) - \sqrt{3}\sin(x) = 2\) as \(2\sin\!\left(x + \dfrac{5\pi}{6}\right) = 2\), or \(\sin\!\left(x + \dfrac{5\pi}{6}\right) = 1\). Solving the latter, we get \(x = -\dfrac{\pi}{3} + 2\pi k\) for integers \(k\). Only one of these solutions, \(x = \dfrac{5\pi}{3}\), which corresponds to \(k = 1\), lies in \([0,2\pi)\).

We repeat here the advice given when solving systems of nonlinear equations — when it comes to solving equations involving the trigonometric functions, it helps to just try something.
